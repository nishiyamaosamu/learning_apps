## 用語の呼称（★ この回が主担当。以降の回はここに揃える）

| 語 | この回での定義（読み上げ文そのまま） |
|---|---|
| **リスク対応** | 評価で順位が付いたリスクに、どう手を打つかを決めること |
| **リスク回避** | リスクの原因ごとやめてしまうこと（原因になっている活動そのものをやめる判断。得られたはずの利益も一緒に手放す） |
| **リスク共有**（＝リスク移転・リスク分散） | リスクを他者と分け合うこと。**保険や外部委託が移転**、**拠点やデータを複数に分けるのが分散** |
| **リスク保有** | 対策をとらずに受け入れること（小さなリスクまで潰すとコスト倒れになるので、あえて選ぶ積極的な判断） |
| **リスク低減** | 対策で被害を小さくすること（事故の起こりやすさ・起きたときの影響を下げる。実務でもっとも多く選ばれる） |
| リスクコントロール | 損失そのものを抑えるやり方。**回避・低減・分散**が入る |
| リスクファイナンシング | お金で備えるやり方。**移転（保険）・保有**が入る |
| リスクヘッジ | 損失に備えて手を打っておくこと（サイバー保険がその例） |
| 残留リスク | 対応をとったあとに残る分。リスク基準に照らして確かめ、保有として引き受けて見直しを続ける |
| リスク集約 | 似たリスクをまとめて一つの対応で扱うこと |
| リスク対応計画 | だれが、いつまでに、何をするかを決めるもの |
| リスク登録簿 | リスクと対応の状況を記録する一覧 |
| リスクコミュニケーション | 関係者と情報を共有して認識を合わせること |

**呼称の固定**（後続の回はここに従う）:

1. **4分類は「リスク回避・リスク共有・リスク保有・リスク低減」と呼ぶ**。「リスク移転」は
   共有の中の一形態（保険・外部委託）として扱い、4分類の名前としては使わない
   — JIS Q 27000 系の呼称に合わせ、移転と分散の両方を1つの分類でくくるため
2. **読み上げの順番は「回避 → 共有 → 保有 → 低減」に固定**する（発注書の並び。
   L66・L73・L81 も同じ順で並べる）
3. **画面表記は「やめる／分け合う／受け入れる／小さくする」の動詞を添える**
   （用語だけだと4つの区別が付かないため。用語が主・動詞が従属）
4. リスク保有は「対策できないから仕方なく」ではなく**積極的な判断**として語る（発注書の指定）

## 原稿（字幕＝読み上げテキスト。1文＝1セグメント＝字幕1枚）

### s02 導入：測り終えた次にやること（custom：左テキスト＋右イラスト person-leader-idea.png）
1. 前回のリスクアセスメントで、リスクに優先順位が付きました。
2. 今回は、そのリスクにどう手を打つかを決める、リスク対応を学びます。
3. 打ち手は思いつきで選ばず、四つの型から選びます。
4. どれを選ぶかは、費用と効果を見比べた経営の判断になります。

### s03 4分類の顔見せ（custom：横4列・囲みなし）★主担当
1. 測ったリスクへの手の打ち方は、大きく四つに分けられます。
2. 一つ目のリスク回避は、リスクの原因ごとやめてしまうことです。
3. 二つ目のリスク共有は、リスクを他者と分け合うことです。
4. 三つ目のリスク保有は、対策をとらずに受け入れることです。
5. 四つ目のリスク低減は、対策で被害を小さくすることです。

### s04 両極の判断（vs：リスク回避／リスク保有・columnAtSec で左右を同期）
1. まずは、両極にある回避と保有を並べて見てみましょう。
2. リスク回避は、原因になっている活動そのものをやめる判断です。
3. 危険は消えますが、得られたはずの利益も一緒に手放します。
4. リスク保有は、対策をとらずにそのまま受け入れる判断です。
5. 小さなリスクまで潰すとコスト倒れになるので、あえて選ぶ積極的な判断です。

### s05 リスク共有の2つの形（custom：用語見出し＋横長2行）
1. 次は、リスクを他者と分け合うリスク共有です。
2. 保険をかけたり、業務を外部に委託したりするのがリスク移転です。
3. 拠点やデータを複数に分けて、同時にやられないようにするのがリスク分散です。
4. どちらも、自分だけで背負わない形に組み替える対応です。

### s06 リスク低減（custom：左キーワード見出し＋右2カード＋対策チップ）
1. 四つの中で、実務でもっとも多く選ばれるのがリスク低減です。
2. 対策によって、事故の起こりやすさや、起きたときの影響を小さくします。
3. バックアップや暗号化、社員教育といった具体的な対策が、ここに入ります。

### s07 もう一つの切り口（custom：2列の振り分け表・wipe-lightで章転換）
1. 四つの分類を、別の切り口でも整理しておきましょう。
2. 損失そのものを抑えるやり方が、リスクコントロールです。
3. 回避、低減、そして拠点を分ける分散が、ここに入ります。
4. お金で備えるやり方が、リスクファイナンシングです。
5. 保険による移転や、自分で負担する保有が、ここに入ります。
6. サイバー保険のように、損失に備えて手を打っておくことをリスクヘッジと呼びます。

### s08 【抽象→具体】一つのリスクで比べる（custom：リスク帯＋2×2の打ち手カード）
1. 一つのリスクにあてはめると、四つの違いがはっきりします。
2. 営業がノートPCを持ち出して、顧客名簿が漏れるリスクで考えます。
3. 持ち出しを禁止すれば回避、保険をかければ共有、暗号化すれば低減です。
4. 影響が小さいと判断してそのままにするなら、それが保有です。

### s09 残留リスク（custom：横バーが縮み、残りがピンクで残る）
1. どの対応を選んでも、リスクがゼロになることはありません。
2. 対応をとったあとに残る分を、残留リスクといいます。
3. 残留リスクが受け入れられる大きさかを、リスク基準に照らして確かめます。
4. そのうえで保有として引き受け、定期的に見直していきます。

### s10 関連用語の地図（custom：左4行リスト＋右イラスト prop-ledger.png）
1. 最後に、リスク対応のまわりの言葉を、まとめて押さえます。
2. 似たリスクをまとめて一つの対応で扱うのが、リスク集約です。
3. だれが、いつまでに、何をするかを決めるのが、リスク対応計画です。
4. リスクと対応の状況を記録する一覧が、リスク登録簿です。
5. 関係者と情報を共有して認識を合わせるのが、リスクコミュニケーションです。

### s11 クイズ幕間（SectionTitle・共通音声 QUIZ_INTRO_SEG）
1. ここまで学んだことを、クイズ形式で確認していきましょう。

### s12 クイズ①（サイバー保険＝共有・正解B）
1. ここで問題です。
2. 情報漏えいに備えてサイバー保険に加入するのは、どの対応でしょうか。
3. （考える間 1.8秒）正解は、リスク共有です。

### s13 クイズ②（保有が正しい判断になる条件・正解A）
1. 次の問題です。
2. リスク保有を選ぶのが適切なのは、どんなときでしょうか。
3. （考える間 1.8秒）正解は、損失が小さく、対策の費用のほうが高くつくときです。

### s14 クイズ③（残留リスク・正解B）
1. 最後の問題です。
2. 対応をとってもなお残るリスクを、何と呼ぶでしょうか。
3. （考える間 1.8秒）正解は、残留リスクです。

### s15 まとめ（summary・wipeで転換・共通音声 OUTRO_SEG）
1. リスク対応は、回避、共有、保有、低減の四つから選びます。
2. 損失を抑えるコントロールと、お金で備えるファイナンシングで整理できます。
3. 残った分は残留リスクとして引き受け、見直しを続けます。
4. 今回のレッスンはここまでです。お疲れさまでした！（共通音声）
