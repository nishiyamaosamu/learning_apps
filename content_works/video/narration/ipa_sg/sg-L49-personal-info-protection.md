## 用語の呼称（この回が正。L50・L92 はこれに揃える）

| 用語 | この回での言い方 |
|---|---|
| 個人情報 | **生存する個人**に関する情報のうち、特定の個人を識別できるもの。氏名・顔写真・生年月日と氏名の組み合わせが典型。**亡くなった方の情報は含まない** |
| 容易照合性 | その情報だけでは誰か分からなくても、**他の情報と容易に照合して特定できれば個人情報**（例: 社員番号だけの一覧表＋社内名簿） |
| 個人情報取扱事業者 | 個人情報をデータベースにして事業に使う者。**規模は関係なく、ほとんどの会社が該当** |
| 要配慮個人情報 | 人種・信条・病歴・犯罪の経歴など。知られると差別や偏見につながるおそれがある情報。**取得の時点で本人の同意が必要** |
| 安全管理措置 | 集めた個人情報を漏らさないように守る義務。**組織的・人的・物理的・技術的**の四つ（L29 の管理策4区分と同じ骨組み・同じ順） |
| 第三者提供 | 集めた個人情報を他社に渡すこと。**原則は本人の同意が必要** |
| オプトイン | 先に同意をもらう方式（＝原則） |
| オプトアウト | 本人が求めれば止める約束で先に提供する方式。**個人情報保護委員会への届け出が必要**で、**要配慮個人情報には使えない** |
| 個人情報保護委員会 | 独立した監督官庁。報告を求める・立入検査・命令の権限を持つ。**漏えいしたときの報告先**でもあり、本人への通知もあわせて必要 |

安全管理措置の四つは **組織的 → 人的 → 物理的 → 技術的** の順で固定（L29 と同じ。
第4章 L34〜L41 もこの順）。

## ナレーション原稿

### s02 導入 — どれも個人情報
1. 会社が持っている顧客名簿や、アンケートの回答用紙。
2. 防犯カメラに映った、お客さまの顔の映像。
3. これらはすべて、法律が守る個人情報にあたります。
4. 今回は、集めた側に課されるルールを見ていきます。

### s03 個人情報とは
1. まず、個人情報とは何かをはっきりさせましょう。
2. 個人情報とは、生存する個人に関する情報のことです。
3. その中でも、特定の個人を識別できるものを指します。
4. 氏名や顔写真、生年月日と氏名の組み合わせが典型です。
5. 生存する、とあるので、亡くなった方の情報は含みません。

### s04 ★抽象→具体：容易照合性
1. ここで、試験でよく問われる考え方があります。
2. たとえば、社員番号だけが並んだ一覧表があるとします。
3. これだけでは、誰のことなのか分かりません。
4. ですが、社内の名簿と照らせば、すぐに誰かが分かります。
5. このように容易に照合できるものも、個人情報です。

### s05 個人情報取扱事業者
1. 次は、このルールを守る側を見ていきましょう。
2. 個人情報をデータベースにして事業に使う人が対象です。
3. これを、個人情報取扱事業者といいます。
4. 規模は関係なく、ほとんどの会社が当てはまります。
5. うちは小さいから関係ない、は通りません。

### s06 要配慮個人情報（wipe-light）
1. 個人情報の中には、とくに慎重に扱うものがあります。
2. 人種、信条、病歴、犯罪の経歴などがそれにあたります。
3. これらを、要配慮個人情報といいます。
4. 知られると、差別や偏見につながるおそれがあるためです。
5. 取得する時点で、本人の同意が必要になります。

### s07 安全管理措置
1. 集めた個人情報は、漏らさないように守る義務があります。
2. これを、安全管理措置といいます。
3. 中身は、組織的、人的、物理的、技術的の四つに分かれます。
4. 規程を決め、研修をし、鍵をかけ、アクセス制御をかける。
5. 以前学んだ管理策の四区分と、同じ骨組みです。

### s08 第三者提供とオプトイン
1. 集めた個人情報を、他社に渡す場合はどうでしょうか。
2. これを第三者提供といい、原則は本人の同意が必要です。
3. 先に同意をもらうこの方式を、オプトインといいます。
4. 同意なく名簿を売り渡すのは、この原則に反します。

### s09 オプトアウト
1. もう一つ、オプトアウトという方式もあります。
2. 本人が求めれば止める約束で、先に提供する方式です。
3. 使うには、個人情報保護委員会への届け出が必要です。
4. そして、要配慮個人情報には、この方式を使えません。
5. 慎重に扱う情報は、必ず事前の同意が要るのです。

### s10 個人情報保護委員会
1. 最後に、これらを見張る役所を見ておきましょう。
2. 個人情報保護委員会という、独立した監督官庁です。
3. 報告を求め、立入検査をし、命令を出す権限があります。
4. 個人情報が漏えいしたときの報告先も、この委員会です。
5. 本人への通知も、あわせて必要になります。

### s15 まとめ（wipe）
1. 個人情報は、生存する個人を識別できる情報でした。
2. 集めた側には、安全管理措置と提供のルールがあります。
3. 要配慮個人情報は、取得に同意が必要な特別扱いです。
4. 共通音声 `OUTRO_SEG`
