## 範囲の切り分けメモ

- **対策そのものには踏み込まない**（誓約書・教育・訓練・内部不正防止ガイドライン → L34、
  科目Bの内部不正ケース → L95）。この回は「なぜ起きるか」と「どこを崩すか」の原理まで
- 攻撃者の種類は **スクリプトキディ／愉快犯／詐欺犯／内部犯** の4つだけ。
  ハクティビズム・サイバーテロ・RaaS・リークサイトは L13
- ダークウェブは「盗品と攻撃ツールの市場」までで止める（ビジネス化の本編は L13）
- ボットハーダー・二重脅迫には触れない（L5）

## 原稿（字幕＝読み上げテキスト。1文＝1セグメント＝字幕1枚）

### s02 導入：ふつうの人が不正をする（custom：左テキスト＋右イラスト person-employee-m-worry.png）
1. 今回は、なぜ人は不正をしてしまうのかを学びます。
2. 情報を持ち出す事件の多くは、社内の人が起こしています。
3. しかも、もともと悪い人が起こしたわけではありません。
4. 条件がそろったとき、ふつうの人が不正に手を染めてしまうのです。

### s03 ★不正のトライアングル（custom：SVG三角形・頂点が順に灯る）
1. 不正が起きるしくみを説明するのが、不正のトライアングルです。
2. 一つめは機会。誰も見ていない、いつでも持ち出せるという状況です。
3. 二つめは動機。借金や過大なノルマなど、そうせざるを得ない事情です。
4. 三つめは正当化。自分は正当に評価されていない、という都合のよい理屈です。
5. この三つがそろったときに、不正は起こります。

### s04 どこを崩せるか（custom：3カード＋可否バッジ＋結論バンド）
1. 裏を返せば、三つのうち一つでも崩せば、不正は防げます。
2. ただし、動機と正当化は、その人の内側にある気持ちです。
3. 組織が直接手を出せるのは、主に機会の側になります。
4. だから対策の中心は、不正をやりにくい状況をつくることです。

### s05 状況的犯罪予防（custom：見出しドン）
1. この考え方を、状況的犯罪予防と呼びます。
2. 人の心を変えるのではなく、環境のほうを変える発想です。
3. ねらいの一つめは、やりにくくすること。
4. 二つめは、見つかりやすくすることです。
5. 持ち出しにくく記録が残る職場なら、機会そのものが消えていきます。

### s06 割れ窓理論（flow：乱れ→放置→不正）
1. もう一つ、割れ窓理論という考え方があります。
2. 割れた窓を放置した建物は、次々と壊されていくという理論です。
3. 職場も同じで、小さな乱れを放置すると、やがて大きな不正を呼びます。
4. だから、清掃や整理整頓が、りっぱなセキュリティ対策になります。

### s07 防犯環境設計（bullets＋illust scene-entrance.png）
1. 物理的な場所づくりにも、同じ発想があります。
2. 防犯環境設計は、建物や部屋のつくりで犯行の機会を減らす考え方です。
3. まず見通しをよくして、死角をなくします。
4. 次に動線を絞り、通れる場所を限ります。
5. そして監視の目を届かせ、記録が残るようにします。

### s08 攻撃者の地図（custom：2×2グリッド／wipe-light）
1. ここからは、実際に攻撃してくる人たちを見ていきます。
2. スクリプトキディは、公開された攻撃ツールを使うだけの初心者です。
3. 愉快犯は、騒ぎを起こして注目されること自体が目的です。
4. 詐欺犯は、金銭が目的で、いまの攻撃の主流になっています。
5. そして内部犯は、正規の権限を持った社内の人です。

### s09 内部犯がいちばん痛い（custom：左イラスト person-insider-sneak.png＋右テキスト）
1. この中で、いちばん痛いのが内部犯です。
2. もともと入る権限があるので、壁を破る必要がありません。
3. どこに大事な情報があるかも、最初から知っています。
4. 外からの侵入を防ぐ対策では、そもそも止められないのです。

### s10 ダークウェブ（term）
1. 最後に、ダークウェブを押さえましょう。
2. 特別なソフトでしかたどり着けない、匿名性の高い領域です。
3. ここでは、盗まれた情報や攻撃ツールが売り買いされています。
4. 攻撃が商売として成り立つ、その入口がここにあります。
