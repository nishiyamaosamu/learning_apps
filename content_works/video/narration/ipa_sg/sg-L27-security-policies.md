## 用語の呼称（L22 に揃える／この回が階層構造の正）

| 語 | この回での定義（読み上げ文そのまま） |
|---|---|
| 情報セキュリティ方針 | 経営層が組織の内外に向けて宣言する最上位の文書。何のために情報を守るのかを示す |
| 対策基準 | 守るべきことを分野ごとに定めるもの。実際には規程の束になっている |
| 実施手順 | 実際の作業のやり方を書くもの。現場の都合で見直す機会がもっとも多い |
| 情報セキュリティポリシーの体系 | 上の三階層の全体を指す言い方 |
| プライバシーポリシー（個人情報保護方針） | 個人情報の扱いを、お客様や取引先など外部に向けて約束する文書 |
| ソーシャルメディアガイドライン | SNSの使い方を定めた規程 |

**呼称の判断**: 三階層の全体は「**情報セキュリティポリシーの体系**」と呼んだ。
「情報セキュリティポリシー」の語は、狭義（方針＋対策基準）と広義（＋実施手順）で
文献の扱いが分かれるため、どちらとも矛盾しない「体系」で受けている（次の回もこれに従う）。

## 原稿（字幕＝読み上げテキスト。1文＝1セグメント＝字幕1枚）

### s02 導入：ルールは一枚では書けない（custom：左イラスト person-employee-f-worry.png＋右テキスト）
1. 今回は、情報セキュリティ諸規程について学びます。
2. 情報を守るルールは、一枚の文書では書き切れません。
3. 情報を守りますという宣言だけでは、現場は何をすればよいか分かりません。
4. 反対に、細かい手順書だけでは、なぜそうするのかが伝わりません。

### s03 三階層（★核心・custom：三段のピラミッド帯）
1. そこで、ルールは三つの階層に分けて作ります。
2. 一番上が情報セキュリティ方針で、何のために守るのかを示します。
3. 真ん中が対策基準で、守るべきことを分野ごとに定めます。
4. 一番下が実施手順で、実際の作業のやり方を書きます。
5. この三階層の全体を、情報セキュリティポリシーの体系と呼びます。

### s04 情報セキュリティ方針（custom：左キーワード見出し＋右イラスト mgmt-committee.png）
1. 一番上の情報セキュリティ方針を、もう少し詳しく見ます。
2. これは、経営層が組織の内外に向けて宣言する最上位の文書です。
3. 何のために情報を守るのか、その目的をここで示します。
4. 経営者の意思として出すからこそ、組織全体が従う根拠になります。

### s05 対策基準は規程の束（custom：2×2の規程カード）
1. 真ん中の対策基準は、実際には規程の束になっています。
2. たとえば、情報の扱い方を定めた情報管理規程です。
3. 事故が起きたときの動き方を定めた、インシデント対応規程もあります。
4. 例外を認めるときの決まりや、規程を承認する手続きも定めます。
5. 組織の事情に合わせて、こうした規程がいくつも並びます。

### s06 どの階層を直すか（custom・wipe-lightで場面転換：左イラスト tech-patch.png＋右に三階層の判定行）
1. では、対策を入れ替えるとき、どの階層を直すのでしょうか。
2. ウイルス対策ソフトを、別の製品に切り替えた場面で考えます。
3. 情報を守るという方針は、変える必要がありません。
4. 不正なプログラムを検知するという対策基準も、そのままです。
5. 直すのは、設定のやり方を書いた実施手順だけです。
6. 上は変えず、下は現場で変えられる。これが三階層の利点です。

### s07 プライバシーポリシーとの違い（vs：情報セキュリティ方針 ／ プライバシーポリシー）
1. ここで、よく似たもう一つの文書と比べておきましょう。
2. 情報セキュリティ方針は、守るべきルールを組織の中に示す文書です。
3. これに対して、プライバシーポリシーという文書があります。
4. 個人情報保護方針とも呼ばれ、個人情報の扱いを定めます。
5. こちらは、お客様や取引先といった外部への約束が中心です。
6. 違いは、誰に向けた宣言かという点にあります。

### s08 ソーシャルメディアガイドライン（custom：左イラスト icon-smartphone.png＋右キーワード見出し）
1. 規程の中には、SNSの使い方を定めたものもあります。
2. これを、ソーシャルメディアガイドラインと呼びます。
3. 業務での投稿の範囲や、個人の投稿で気をつけることを示します。
4. 何気ない投稿から、社内の情報や人間関係が読み取られてしまうからです。

### s09 クイズ幕間（SectionTitle・共通音声 QUIZ_INTRO_SEG）
1. ここまで学んだことを、クイズ形式で確認していきましょう。

### s10 クイズ①（三階層の一番上・正解B）
1. ここで問題です。
2. 三階層の一番上に来るのは、どちらでしょうか。
3. （考える間 1.8秒）正解は、情報セキュリティ方針です。

### s11 クイズ②（見直す機会が多い階層・正解A）

2. 現場の都合で見直す機会が多いのは、どちらでしょうか。
3. （考える間 1.8秒）正解は、実施手順です。

### s12 クイズ③（外部への約束・正解B）

2. 個人情報の扱いを外部に約束する文書は、どちらでしょうか。
3. （考える間 1.8秒）正解は、プライバシーポリシーです。

### s13 まとめ（summary・wipeで転換・共通音声 OUTRO_SEG）
1. ルールは、方針、対策基準、実施手順の三階層で作ります。

3. プライバシーポリシーは、個人情報の扱いを外部に約束する文書です。
