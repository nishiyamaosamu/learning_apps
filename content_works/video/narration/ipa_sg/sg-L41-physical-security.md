## 用語の呼称

| 語 | この回での定義（読み上げ文そのまま） |
|---|---|
| セキュリティゾーニング | 建物のなかを区域に分け、奥へ行くほど入れる人を絞る考え方 |
| 区域の3段 | 誰でも入れる受付 → 社員だけの執務室 → 限られた人だけのサーバ室（この順・この呼び方で固定） |
| 共連れ | 後ろについて一緒に入ること |
| アンチパスバック | 入った記録のない人は、外へ出られない仕組み |
| インターロック | 二重扉。手前の扉が閉じるまで、奥の扉は開かない |
| 監視カメラ | あとから確認でき、見られていると思わせる効果もある（＝L6 の「機会」を減らす） |

| クリアデスク | 退社するとき、机の上に書類を残さない |
| クリアスクリーン | 離席するとき、画面をロックする |
| UPS（無停電電源装置） | 停電に備える設備。電源が切れても、安全に終了する時間を稼げる |
| 耐震設備・耐火設備 | 地震や火災に備える設備 |

## 範囲の切り分けメモ

- **RASIS・RAS技術・稼働率の指標名は一つも出さない**（L56 が主担当）。設備の多重化は
  「片方が壊れても止まらない」という**止めない工夫**としてだけ語る。ミラーリングなどの
  ストレージ技術（L57）にも触れない
- **USBキー・セキュリティケーブルは出さない**（暗記カードの領分）。誘導文も書かない
- **入退室のケース演習（ゲスト入館証・共連れの穴）は L82、媒体・文書管理の点検は L86**
  なので、確認パートは通常クイズ3問（科目Bではない）
- **バックアップの方式・世代管理（フル／差分／増分）は L59** なので、s09 は
  「控えの一つを離れた場所に置く」＝置き場所の話だけで止める。3-2-1ルール（L35）の
  語も出さない（物理側から同じ結論に着地するだけにして、規則名の主担当を侵さない）
- 消去の技術的な手法名（暗号化消去など）は L40 が主担当なので出さず、
  「上書きして完全に消す／物理的に壊す」の平語で締める
- 監視カメラの効果は L6 の「不正が起きる機会」を1文で受けるだけ（不正のトライアングルの
  再説明はしない）
- L29 の「物理的な管理策（入退室の管理や施錠）」の区分をこの回が回収する形になっている

## 原稿（字幕＝読み上げテキスト。1文＝1セグメント＝字幕1枚）

### s02 導入（custom：左イラスト person-attacker-sneak.png ＋右テキスト）
1. 今回は、物理的セキュリティ対策について学びます。
2. どれだけ技術で守っても、その場所に入られたら終わりです。
3. 機器を持ち出されれば、暗号も認証も関係ありません。
4. 場所、人の出入り、設備、そして媒体を守っていきましょう。

### s03 セキュリティゾーニング（custom：入れ子の3ボックス）
1. まずは、建物のなかを区域に分けることから始めます。
2. これをセキュリティゾーニングといいます。
3. 誰でも入れる受付、社員だけの執務室、そしてサーバ室です。
4. 奥へ行くほど、入れる人を絞っていきます。

### s04 ★抽象→具体：取引先の人はどこまで入れるか（custom：場面帯＋3行）
1. たとえば、取引先の人が打ち合わせに来たとしましょう。
2. 受付では入館証を受け取り、誰が来ているかを記録します。
3. 執務室から先は、社員が同行しなければ通れません。
4. サーバ室には、そもそも入る用事がありません。

### s05 入退室管理（custom：問題帯＋2カード）
1. 区域を分けても、扉が素通りできては意味がありません。
2. 後ろについて一緒に入るのが、共連れ（ともづれ）です。
3. そこで使うのが、アンチパスバックです。
4. 入った記録のない人は、外へ出られない仕組みです。
5. もう一つはインターロックで、二重扉になっています。
6. 手前の扉が閉じるまで、奥の扉は開きません。

### s06 監視カメラ・施錠管理（custom：左テキスト＋右イラスト tech-camera.png）
1. 出入りの記録と合わせて効くのが、監視カメラです。
2. あとから確認でき、見られていると思わせる効果もあります。
3. これは、不正が起きる機会そのものを減らす対策です。
4. 鍵も同じで、誰にいつ貸したかを記録して管理します。

### s07 クリアデスク・クリアスクリーン（custom：中央に大タイル2枚）
1. お金をかけずにできる対策もあります。
2. 退社するとき、机の上に書類を残さないのがクリアデスクです。
3. 離席するとき、画面をロックするのがクリアスクリーンです。
4. もっとも安く、もっとも忘れられやすい対策です。

### s08 設備で止めない・壊さない（custom：アイコン3連。wipe-light で章の転換）
1. ここからは、建物の設備の話です。
2. 停電に備えるのが、無停電電源装置、UPSです。
3. 電源が切れても、安全に終了する時間を稼げます。
4. 地震や火災に備えて、耐震設備や耐火設備も置きます。
5. 電源や機器を二重にしておけば、片方が壊れても止まりません。

### s09 遠隔バックアップ（custom：2パネル対比）
1. 控えを取っていても、同じ建物に置いていては共倒れです。
2. 火事や地震は、本番も控えもまとめて奪っていきます。
3. だから控えの一つは、離れた場所に置きます。
4. これを遠隔バックアップといいます。

### s10 記憶媒体の管理と処分（custom：左イラスト tech-shredder.png ＋右2段）
1. 最後は、記憶媒体の管理と処分です。
2. 持ち出しは台帳に記録し、使わないときは鍵のかかる場所へ。
3. そして、捨てるときがいちばん危ない場面です。
4. 削除しただけのデータは、専用のソフトで元に戻せます。
5. 上書きして完全に消すか、物理的に壊してから処分します。
