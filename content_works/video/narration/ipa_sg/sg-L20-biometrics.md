## 難読語・略語の例外（音声と字幕でテキストを分ける）

`N()` の第2引数は字幕にしか使われず、音声は mp3 そのもの。両者が食い違っても再生に影響しない。

| 語 | 音声（jobs.json） | 字幕（.tsx の `N()`） | 理由 |
|---|---|---|---|
| ICカード | アイシーカード | ICカード | 綴りどおり読ませない |
| PINコード | ピンコード | PINコード | 「ピー・アイ・エヌ」と読ませない（定着した読みは「ピン」） |
| FRR | エフアールアール | FRR | 1字ずつ読む略語 |
| FAR | エフエーアール | FAR | 同上（「ファー」と読ませない） |
| eKYC | イーケーワイシー | eKYC | 同上 |
| EMV 3-Dセキュア | イーエムブイスリーディーセキュア | EMV 3-Dセキュア | 同上 |

読みを字幕に添えるのは**初出の1回だけ**。この回では eKYC（s08-1）と EMV 3-Dセキュア（s09-1）の
字幕にカナを併記した（読み方が定着した略語は、音声だけ仮名書きにすると画面から読み方が学べない）。
FRR・FAR は本編で「本人拒否率、略してFRRは…」と日本語の正式名とセットで語り、画面の列タイトルにも
「本人拒否率（FRR）」と併記しているので、字幕にカナは入れていない。
ICカード・PINコードは日常語なので同様にカナなし。

## 原稿（読み上げ＝字幕）

**P2 生体認証（3要素のひとつ）**（s02・116字）
1. 前回は、認証の三つの要素を学びました。
2. 記憶、所有、そして生体の三つですね。
3. 今回は、その中の生体をくわしく見ていきます。
4. 体そのものを鍵にするのが、生体認証です。
5. パスワードのように忘れることも、カードのように失くすこともありません。

**P3 身体的特徴による認証**（s03・118字）
1. 生体認証は、大きく二つに分けられます。
2. 一つめは、身体的特徴による認証です。
3. 体の形やもよう、そのものを証拠として使います。
4. 手のひらの静脈、目の虹彩、顔の形などが代表です。
5. どれも一人ひとり違い、生まれつき変わりにくいのが強みです。

**P4 行動的特徴による認証**（s04・120字）
1. 二つめは、行動的特徴による認証です。
2. こちらは体の形ではなく、動きの癖を証拠にします。
3. 声の高さや話し方の癖を見るのが、声紋による認証です。
4. 手書きの署名なら、書く速さや筆圧の癖まで確かめられます。
5. 形だけまねても、書き方の癖まではまねられません。

**P5 二つの割合（FRR・FAR）**（s05・140字）
1. ここで、生体認証の急所になる二つの割合を覚えます。
2. 本人拒否率、略してFRRは、本人なのに拒まれてしまう割合です。
3. 指が乾いていて読み取れない、といった場面ですね。
4. 他人受入率、略してFARは、他人を本人として通してしまう割合です。
5. 本人拒否率は不便さにつながり、他人受入率は危険に直結します。

**P6 厳しさのトレードオフ**（s06・152字）
1. この二つは、判定の厳しさで同時に決まります。
2. 判定を厳しくすると、他人受入率は下がります。
3. ところが同時に、本人拒否率は上がってしまいます。
4. ゆるくすれば本人は通りやすくなりますが、他人も通りやすくなります。
5. どちらか片方だけをゼロにすることはできません。
6. だから、用途に合わせてちょうどよい厳しさに調整します。

**P7 ICカードとPINコード**（s07・126字）
1. ここからは、本人確認のしくみに目を向けます。
2. 社員証などのICカードは、持っている人だけが使えます。
3. そこに、PINコードという暗証番号を組み合わせます。
4. カードは所有、PINコードは記憶にあたります。
5. 種類の違う二つを重ねるので、カードを盗まれただけでは使えません。

**P8 eKYC**（s08・142字）
1. オンラインで本人確認を済ませるしくみが、eKYCです。
2. 銀行の口座開設などを、窓口に行かずに完結できます。
3. まず、運転免許証などの本人確認書類を撮影します。
4. 次に、自分の顔をその場で撮影します。
5. 送られた二つを照合して、同じ人かどうかを確かめます。
6. 書類の郵送を待たずに、その日から使い始められます。

**P9 EMV 3-Dセキュア**（s09・152字）
1. カード決済の本人確認に使われるのが、EMV 3-Dセキュアです。
2. ネットショップの支払いで、毎回パスワードを求められては面倒です。
3. そこで、ふだんと同じ端末からの支払いは、そのまま通します。
4. いつもと違う端末や、高額な取引のときだけ、追加の確認をします。
5. 前回学んだリスクベース認証を、カード決済に応用したしくみです。

**P11 クイズ1**（s11・51字）
1. ここで問題です。
2. 生体認証の判定を厳しくすると、どうなるでしょうか。
3. 正解は、本人拒否率が上がることです。（考える間 1.8秒）

**P12 クイズ2**（s12・55字）
1. 次の問題です。
2. ICカードとPINコードは、何と何を重ねた組み合わせでしょうか。
3. 正解は、所有と記憶の組み合わせです。（考える間 1.8秒）

**P13 クイズ3**（s13・49字）
1. 最後の問題です。
2. 声紋による認証は、どちらに分類されるでしょうか。
3. 正解は、行動的特徴による認証です。（考える間 1.8秒）

**P14 まとめ**（s14・99字）
1. 生体認証には、身体的特徴と行動的特徴があります。
2. 判定を厳しくすると本人拒否率が上がり、ゆるめると他人受入率が上がります。
3. ICカードとPINコード、eKYC、EMV 3-Dセキュアも本人確認のしくみです。
4. （共通音声 OUTRO_SEG）
