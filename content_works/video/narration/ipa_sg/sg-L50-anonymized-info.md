### 加工してできる二つの情報

| 用語 | この回での言い方 |
|---|---|
| 匿名加工情報 | 特定の個人を**識別できず**、**元の個人情報に復元もできない**ように加工した情報。ここまで加工すれば**本人の同意なしで第三者提供できる**（活用と保護の両立が制度の狙い） |
| 仮名加工情報 | **他の情報と照合しなければ**特定の個人を識別できない状態に加工した情報。加工の程度が弱いぶん**第三者提供は原則できない**。社内の分析に使う「内向きの加工」 |

### 匿名加工の手法名（★主担当。この6つの呼称が正）

**削る**（3つ）と**ぼかす**（3つ）の2方向＋高度な手法として k-匿名化、という並べ方で固定する。

| 手法名 | この回での言い方（操作） | 例 |
|---|---|---|
| 項目削除 | 表の**列**（項目）そのものを消す | 氏名の列を丸ごと消す |
| レコード削除 | 表の**行**（1件分）をまるごと消す | 特異な1人の行を消す |
| セル削除 | 表の**一つのマス**だけを消す | ある人の年齢だけ空にする |
| 一般化 | 記述を**上位の概念に置き換える** | きゅうり → 野菜 |
| トップ（ボトム）コーディング | 極端に**大きい（小さい）値をまとめる** | 115歳 → 80歳以上 |
| 丸め | 数値を**四捨五入などして丸める** | 34歳 → 30代 |
| k-匿名化 | 同じ属性の組み合わせの人が**必ずk人以上**いるようにする（高度な手法） | 3人そろうまで年代・地域をぼかす |

- 「トップコーディング」は**大きい側**、「ボトムコーディング」は**小さい側**。試験・資料では
  「トップ（ボトム）コーディング」と一括で書かれるので、画面では
  `トップ（ボトム）コーディング` と表記し、読み上げでは2文に分けて説明する
- 削る3つは**列・行・マス**という「表のどこを消すか」で区別させる（これが試験の急所）
- k-匿名化は「削る／ぼかす」のどちらかではなく、**ぼかし方の到達目標**として置く

### 周辺の制度

| 用語 | この回での言い方 |
|---|---|
| 特定個人情報 | **マイナンバーを含む個人情報**の呼び名 |
| マイナンバー法 | 特定個人情報の扱いを定める法律。**通常の個人情報より厳格**（利用できる目的が限られ、他社への提供も制限される） |
| JIS Q 15001 | 個人情報を守る**仕組みの規格** |
| プライバシーマーク | 規格に沿った仕組みがあると認められた事業者が使える**認証マーク**。**個人情報版の ISMS 認証**（L29 の ISMS 適合性評価制度との対比で言う） |
| OECDプライバシーガイドライン | 各国の個人情報のルールの**土台になった勧告** |
| GDPR | ヨーロッパの**厳しい個人データ保護の規則** |
| PIA（プライバシー影響アセスメント） | 新しい仕組みを作る**前に**、プライバシーへの影響を評価する取り組み |

## ナレーション原稿

### s02 導入 — 使いたい、でも渡せない
1. 集めた個人情報を、統計や分析に使いたいことがあります。
2. ですが、本人の同意なしに他社へ渡すことはできません。
3. そこで、誰の情報か分からないように加工する道があります。
4. 今回は、その加工の作法と、周りの制度を見ていきます。

### s03 匿名加工情報
1. まず、加工してできる情報の一つ目です。
2. 特定の個人を識別できず、元に戻すこともできない情報です。
3. これを、匿名加工情報といいます。
4. ここまで加工すれば、本人の同意なしで第三者に提供できます。

### s04 ★抽象→具体：歩数アプリのデータ
1. たとえば、歩数を記録するアプリの利用データです。
2. 保険会社と組んで、健康と歩数の関係を分析したいとします。
3. 氏名やメールアドレスを消し、年齢を年代にまとめて渡します。
4. 誰のデータか分からなくなるので、同意なしでも提供できます。

### s05 仮名加工情報（vs）
1. もう一つ、仮名加工情報という形もあります。
2. 他の情報と照合しなければ、個人を特定できない状態です。
3. 加工の程度が弱いぶん、第三者への提供は原則できません。
4. 社内で分析に使うための、いわば内向きの加工です。

### s06 削る三つ（wipe-light）
1. ここからは、匿名加工の手法に名前をつけていきます。
2. 一つ目は、項目そのものを消す項目削除です。
3. 二つ目は、特定の一行をまるごと消すレコード削除です。
4. 三つ目は、表の一つのマスだけを消すセル削除です。
5. まずは、消してしまうのが基本の三つです。

### s07 ぼかす三つ
1. 次は、消さずにぼかす手法です。
2. 一般化は、きゅうりを野菜のように、上位の概念へ置き換えます。
3. トップコーディングは、極端に大きい値をまとめる手法です。
4. 小さい側をまとめる場合は、ボトムコーディングと呼びます。
5. 丸めは、34歳を30代とするように、数値を丸めることです。
   （音声のみ「さんじゅうよんさい を さんじゅうだい」と仮名書き）

### s08 k-匿名化
1. さらに進んだ手法が、k-匿名化です。（音声のみ「ケー匿名化」）
2. 同じ属性の組み合わせの人が、必ずk人以上いるようにします。（音声のみ「ケー人以上」）
3. たとえば、三人以上そろうまで年代や地域をぼかしていきます。
4. 一人だけの組み合わせが残ると、そこから特定されるからです。

### s09 マイナンバー法と特定個人情報
1. ここからは、周りの制度に目を向けます。
2. マイナンバーを含む個人情報は、特定個人情報と呼ばれます。
3. 扱いはマイナンバー法で定められ、通常より厳格です。
4. 利用できる目的が限られ、他社への提供も制限されています。

### s10 JIS Q 15001 とプライバシーマーク
1. 個人情報を守る仕組みにも、規格と認証制度があります。
2. 規格の名前は、JIS Q 15001 といいます。（音声のみ仮名書き）
3. これに沿った仕組みがあると認められると、マークを使えます。
4. それがプライバシーマーク、個人情報版のISMS認証です。（音声のみ「アイエスエムエス」）

### s11 国際的な枠組みの地図
1. 最後に、国際的な枠組みを三つ押さえておきましょう。
2. まず、OECDプライバシーガイドラインです。（音声のみ「オーイーシーディー」）
3. 各国の個人情報のルールの土台になった勧告です。
4. GDPRは、ヨーロッパの厳しい個人データ保護の規則です。（音声のみ「ジーディーピーアール」）
5. PIAは、新しい仕組みの前に影響を評価する取り組みです。（音声のみ「ピーアイエー」）
