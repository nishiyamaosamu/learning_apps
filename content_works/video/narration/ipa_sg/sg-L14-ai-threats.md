## 原稿

### s02 導入
1. これまで、いろいろな攻撃の手口を見てきました。
2. そこにAIが加わって、攻撃の景色が変わりました。
3. まったく新しい攻撃が生まれた、という話ではありません。
4. 今までの攻撃が、速く、安く、それらしくなったのです。

### s03 AIが変えたのは質と量
1. AIが攻撃側にもたらしたのは、質と量の底上げです。
2. まず、下調べや文面づくりが自動化され、攻撃が速くなります。
3. 次に、人手をかけずに大量に仕掛けられるので、安くなります。
4. そして出来上がったものが、本物らしく見えてしまいます。

### s04 フィッシング・ビジネスメール詐欺の巧妙化
1. その影響が最初に出たのが、フィッシングやビジネスメール詐欺です。
2. これまでは、日本語の不自然さが見分ける手がかりでした。
3. ところがAIは、自然で丁寧な日本語をいくらでも書けます。
4. 会社の公開情報を読み込ませれば、社内の言い回しまで真似られます。
5. 文面が自然だから本物、という判断はもう通用しません。

### s05 亜種マルウェアの大量生成
1. マルウェアの世界でも、同じことが起きています。
2. AIを使えば、少しずつ違う亜種を大量に作り出せます。
3. 見た目の特徴で照合するパターンマッチングは、そこが弱点になります。
4. 知らない形の亜種は、既知の一覧に載っていないからです。

### s06 脆弱性発見の効率化
1. 攻撃の下調べも、AIで一気に速くなりました。
2. プログラムの弱いところを、機械が短時間で探し当てます。
3. その結果、弱点が見つかってから攻撃されるまでの時間が縮みます。
4. あとでパッチを当てよう、では間に合わなくなってきています。

### s07 ディープフェイク
1. さらに、声や映像そのものを作れるようになりました。
2. AIで偽造された音声や映像を、ディープフェイクと呼びます。
3. 実在の人の声で、実在の人の顔で、偽の指示が届きます。
4. 電話で本人の声だったから、という理由はもう根拠になりません。
5. 送金や重要な指示は、別の手段で確かめる必要があります。

### s08 敵対的サンプル（ここから AI が狙われる側／wipe-light）
1. ここからは、AIが狙われる側になる話です。
2. 人には分からないわずかな細工を、データに混ぜ込みます。
3. すると、AIの判断だけが大きく狂います。
4. こうしたデータを、敵対的サンプルと呼びます。
5. 止まれの標識が、別の標識だと認識される例が知られています。

### s09 プロンプトインジェクション
1. もう一つ、AIへの入力を悪用する攻撃があります。
2. プロンプトインジェクションと呼ばれる手口です。
3. AIに渡す文章の中に、こっそり別の指示を紛れ込ませます。
4. AIはそれを命令だと受け取り、隠すべき情報まで答えてしまいます。
5. AIに読ませる文章は、それ自体が攻撃の入口になりうるのです。

2. 文面の自然さや、本人の声は、もう本物である根拠になりません。
3. そしてAI自身も、敵対的サンプルなどで狙われる側になっています。
4. 共通音声 `OUTRO_SEG`
