## 原稿（字幕＝読み上げテキスト。1文＝1セグメント＝字幕1枚）

### s02 導入：関所を「どう設定するか」（custom：番号つきアイコン3連）【背骨】
1. ネットワークの守りでは、社内と外との境目に関所を置くことを学びました。
2. 今回は、その関所をどう設定するのかを見ていきます。
3. 通す相手を絞る、通り道を守る、受け方を工夫する。この三つで整理します。

### s03 ①パケットフィルタリングの実装（custom：実際の設定表）
1. まずは、通す相手を絞る設定からです。
2. ファイアウォールには、こんなルールを一行ずつ書いていきます。
3. 送信元のIPアドレス、宛先、そしてポート番号の組み合わせで、許可か拒否かを決めます。
4. 上から順に照合し、どれにも当てはまらない通信は拒否する。これが基本の形です。

L38 が「荷札だけを見る方式＝パケットフィルタリング」を定義済みなので、**定義には戻らず**
「実際のルールはこう書く」だけを見せる（発注書の「設定の目線で再訪」）。

### s04 ①MACアドレスフィルタリング（custom：キーワード見出し＋機器3台）
1. 通信ではなく、つなぐ機器そのもので絞る方法もあります。
2. ネットワーク機器には、MACアドレスという固有の番号が付いています。
3. あらかじめ登録した番号の機器だけを接続させるのが、MACアドレスフィルタリングです。
4. ただし、この番号は書き換えて偽装できるので、これだけに頼ってはいけません。

### s05 ①認証サーバと認証VLAN（flow：3ステップ・語りに同期して点灯）
1. 機器ではなく、使う人を確かめる方法が認証サーバです。
2. ネットワークにつないだだけでは、まだ中には入れません。
3. 利用者のIDとパスワードを認証サーバが確認して、はじめて通信を許します。
4. さらに、確認できた人を所属に応じたネットワークへ割り当てるのが、認証VLANです。

### s06 具体場面：会議室の差込口（custom：1つの口から2本に分岐）【★抽象→具体】
1. 会議室のネットワークを例に見てみましょう。
2. 来客がつないだ場合は、インターネットだけが使える来客用のネットワークにつながります。
3. 同じ差込口でも、社員がつなげば、社内のサーバまで使える社内ネットワークになります。
4. つなげた、イコール、入れた。認証VLANの狙いはここです。

### s07 ②VPN（custom：左テキスト＋右イラスト。wipe-lightで転換）
1. 二つ目は、通り道そのものを守る方法です。
2. インターネットは、誰もが使う公衆の道です。
3. その上に暗号化された専用のトンネルを作るのが、VPNです。
4. 外出先からでも、社内にいるのと同じように安全につなげます。
5. トンネルの中身を暗号化する仕組みには、以前学んだIPsecなどが使われます。

IPsec は L42 が主担当。**仕組みには踏み込まず**「使われます」の一言だけで渡す。

### s08 ③リバースプロキシ（custom：横並び配置図。wipe-lightで転換）
1. 三つ目は、外からの受け方を工夫する方法です。
2. 公開しているサーバに、外から直接つながせたくはありません。
3. そこで、手前に代理の窓口を置いて、そこで受けて中継します。
4. これがリバースプロキシで、本体を直接さらさずに済みます。

### s09 ③ハニーポット（custom：左イラスト＋右テキスト）
1. 最後は、守るだけではない、変わった仕掛けです。
2. わざと弱そうに見えるおとりのサーバで、攻撃者を誘い込みます。
3. これがハニーポットで、蜜の壺という意味の名前です。
4. 目的は防ぐことではなく、どんな手口で来るのかを観察して、本番の守りに活かすことです。
