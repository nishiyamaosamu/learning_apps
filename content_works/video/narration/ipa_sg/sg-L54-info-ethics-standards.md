## ナレーション原稿

### s02 導入＋見取り図 — 身近な場面それぞれに、ルールがある
1. 会社の書類を、紙ではなく電子で保存する。
2. ネットで見かけた話を、確かめずに広めてしまう。
3. どちらにも、守るべきルールや心構えがあります。
4. 今回の話は、大きく三つに分かれます。
5. 電子化を支える法律、情報を扱う心構え、そして標準化です。

### s03 電子化を支える法律の二階建て
1. まずは、電子化を支える法律です。
2. 上の階には、国の方向を示す基本法が並びます。
3. デジタル社会形成基本法が、社会の目指す姿を定めます。
4. 官民データ活用推進基本法が、データの活用を進めます。
5. 下の階には、紙の保存を電子でよいとする法律があります。

### s04 e-文書法と電子帳簿保存法
1. 一つが、e-文書法です。
2. 保存が義務づけられた文書を、電子でも保存できると定めます。
3. もう一つが、電子帳簿保存法です。
4. 帳簿や請求書といった、国税に関する書類が対象です。
5. 紙で受け取った書類も、読み取って電子で保存できます。

### s05 ★抽象→具体：経理の書類が電子になる
1. 場面で見てみましょう。経理の書類がたまるオフィスです。
2. これまでは、請求書を紙のまま何年も保管していました。
3. いまは、読み取って電子データで残すことが認められています。
4. 保管の場所も、探す手間も、大きく減らせます。

### s06 偽・誤情報の三分類（wipe-light）
1. 正しくない情報は、三つに分けられます。
2. だますつもりの偽情報が、ディスインフォメーションです。
3. 意図はないのに広まる誤りが、ミスインフォメーションです。
4. 三つ目は、事実なのに人を傷つける目的で使うものです。
5. これを、マルインフォメーションといいます。
6. 見分ける鍵は、だます意図や悪意があるかどうかです。

### s07 ファクトチェック
1. 広める前に、その情報の出どころを確かめます。
2. これを、ファクトチェックといいます。
3. 発信元は誰か、いつの話か、他ではどう伝えているか。
4. 確かめないまま広めると、自分も広げる側になります。

### s08 デジタルタトゥー
1. 一度ネットに出た情報は、完全には消せません。
2. 保存され、転載され、後からでも掘り起こされます。
3. この消えない足あとを、デジタルタトゥーと呼びます。
4. 投稿する前に、一呼吸おく習慣が身を守ります。

### s09 フィルタリングとペアレンタルコントロール
1. 有害なサイトへのアクセスを止めるのが、フィルタリングです。
2. 使える時間やアプリを、保護者が決める仕組みもあります。
3. これを、ペアレンタルコントロールといいます。
4. 会社の通信を見張る仕組みと違い、守る相手は子どもです。

### s10 標準化の地図（JIS・ISO・IEEE）
1. 最後は、世界共通のものさしを作る標準化です。
2. 決まりを統一しておくと、誰が作っても組み合わせられます。
3. 日本の国内規格を定めるのが、JISです。
4. 国をまたぐ国際規格を定めるのが、ISOです。
5. 電気や通信の分野で規格を定めるのが、IEEEです。

### s11 デジュレとデファクト（vs）
1. 公の機関が定めた標準が、デジュレスタンダードです。
2. これまで学んだJIS Q 27001も、その一つです。
3. 広く使われた結果、事実上の標準になったものもあります。
4. これを、デファクトスタンダードといいます。
