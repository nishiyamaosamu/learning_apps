## この回の位置づけ

第6章（法務）の2本目。L47（知的財産権・不正競争防止法）と同じ
**「何を守る法か・何をすると違反か」の型**で、2つの法律を扱う。

- **サイバーセキュリティ基本法** = 国全体の土台（責務・戦略・協議会）
- **不正アクセス禁止法** = やってはいけない行為（不正アクセス行為・助長する行為）

### 扱わない（発注書どおり）

- NISC・サイバーセキュリティ戦略本部の役割 → L31（s05 で「以前学んだ」と1文つなぐだけ）
- ウイルス作成罪・電子計算機使用詐欺罪などの刑法の罪 → L51（この回では語も出さない）
- パスワードを守る技術側の対策 → L18（触れない）
- 個人情報を盗まれた場合の扱い → L49
- フィッシング行為の禁止（不正アクセス禁止法の一部だが、手口としては L10 の領分）→ 出さない

## 用語の呼称（この回が正）

| 用語 | この回での言い方 |
|---|---|
| サイバーセキュリティ基本法 | 国全体でどう守っていくかの土台を決めた法律 |
| 責務 | 国・地方公共団体・事業者・国民それぞれが負う役割。国民は「関心を持ち、注意を払うよう努める」 |
| サイバーセキュリティ戦略 | 国がこれから何をするかをまとめた計画 |
| サイバーセキュリティ協議会 | 国や企業が集まり、攻撃の情報を共有する枠組み |
| 不正アクセス禁止法 | やってはいけない行為をはっきり決めた法律 |
| 不正アクセス行為 | ①他人のIDとパスワードを使うなりすまし ②システムの弱点を突いた侵入。**どちらもネットワークを通じて行われることが要件** |
| ネットワーク越しの要件 | 目の前のパソコンを直接操作するのは、この法律の対象外 |
| アクセス制御機能 | IDとパスワードなどで利用者を確かめる仕組み。**これを備えたコンピュータだけが守られる** |
| 助長する行為 | 他人のパスワードを無断で第三者に教える・売る。**自分が一度もログインしなくても罰の対象** |
| 成立の考え方 | ログインした時点で違反。**被害が無くても犯罪**（罰則もある） |

罰則は「定められている」までにとどめ、**具体的な刑名・年数・金額は出さない**
（刑法改正で刑名の呼び方が動いており、教材として揺れを持ち込まないため。試験で問われるのは
「被害が無くても成立する」「助長行為も罰される」の側）。

## ナレーション原稿

### s02 導入 — その一回のログイン
1. 会社のパソコンには、必ずIDとパスワードがあります。
2. では、同僚のIDで勝手にログインしたら、どうでしょうか。
3. 実はこれ、法律で禁じられた、れっきとした犯罪です。
4. 今回は、国の方針を決める法律と、この禁止のルールを見ます。

### s03 今回の見取り図
1. 今回学ぶ法律は、二つあります。
2. 一つ目は、サイバーセキュリティ基本法です。
3. 国全体で、どう守っていくかの土台を決めた法律です。
4. 二つ目は、不正アクセス禁止法です。
5. こちらは、やってはいけない行為を、はっきり決めています。

### s04 基本法：みんなに責務がある
1. サイバーセキュリティ基本法の柱は、責務を決めたことです。
2. 国は、全体の方針を作り、対策を進める役割を負います。
3. 地方公共団体も、地域の実情に合わせて取り組みます。
4. 事業者は、自分たちの事業を守る努力が求められます。
5. そして私たち国民も、関心を持ち、注意を払うよう努めます。

### s05 基本法にもとづく二つの仕組み
1. この法律にもとづいて、二つの仕組みが動いています。
2. 一つは、サイバーセキュリティ戦略です。
3. 国がこれから何をするかを、まとめた計画にあたります。
4. もう一つは、サイバーセキュリティ協議会です。
5. 国や企業が集まり、攻撃の情報を共有する枠組みです。
6. 戦略本部やNISC（ニスク）も、この法律にもとづく組織です。

### s06 不正アクセス行為の二つの型（wipe-light）
1. ここからは、不正アクセス禁止法です。
2. 禁止されている不正アクセス行為には、二つの型があります。
3. 一つ目は、他人のIDとパスワードを使う、なりすましです。
4. 二つ目は、システムの弱点を突いて入り込む方法です。
5. どちらも、許されていない人が中に入る行為です。

### s07 ネットワークを通じて、が要件
1. ここで、大事な条件が一つあります。
2. 不正アクセス行為は、ネットワークを通じて行われるものです。
3. 目の前のパソコンを直接操作するのは、この法律の対象外です。
4. 離れた場所から、通信を使って入り込む。これが要件です。

### s08 アクセス制御機能を備えたコンピュータ
1. もう一つ、守られるコンピュータにも条件があります。
2. 対象は、アクセス制御機能を備えたコンピュータです。
3. IDとパスワードなどで、利用者を確かめる仕組みのことです。
4. 裏を返すと、パスワードすら無い機器は、対象になりません。
5. 鍵のかかった扉だからこそ、開ける行為が罪になるのです。

### s09 助長する行為
1. この法律は、自分で入る行為だけを罰するのではありません。
2. 他人のパスワードを、無断で第三者に教える。
3. これは、不正アクセスを助長する行為として禁じられています。
4. 売る場合はもちろん、親切のつもりで教えた場合も同じです。
5. 自分は一度もログインしていなくても、罰の対象になります。

### s10 ★抽象→具体：見ただけでも成立する
1. たとえば、席を外した同僚のIDでログインしたとします。
2. 見たのは社内の資料が一つだけで、何も壊していません。
3. それでも、ログインした時点で不正アクセス行為は成立します。
4. 被害が無くても犯罪で、罰則もきちんと定められています。
5. パスワードを教えてもらっていた、では済みません。
6. IDは自分だけのもの。ここが、この法律の考え方です。

3. 正解は、その時点で違反になる、です。（gapBeforeSec 1.8）

### s15 まとめ（wipe）
1. 基本法は、国から国民までの責務を定めた法律でした。
2. 不正アクセス行為は、なりすましと、弱点を突いた侵入です。
3. パスワードを教える行為も罪。被害が無くても成立します。
4. 共通音声 `OUTRO_SEG`
