## 用語の呼称（★ この回が主担当。以降の回はここに揃える）

| 語 | この回での定義（読み上げ文そのまま） |
|---|---|
| リスクアセスメント | リスクの大きさを測って順位をつける、リスク特定・リスク分析・リスク評価の3段階 |
| リスク特定 | どんなリスクがあるかを洗い出す段階 |
| リスク分析 | その大きさを見積もる段階 |
| リスク評価 | 大きさを基準と比べて優先順位を決める段階 |
| リスク基準（＝リスク受容基準） | どこから上を問題とするかを定めた物差し。どこまで受け入れるかを示すのでリスク受容基準とも呼ぶ |
| **リスク値** | **重要度、かける、脅威、かける、脆弱性**（画面表記は `リスク値 ＝ 重要度 × 脅威 × 脆弱性`） |
| 重要度 | 資産の価値（3特性の評価から決まる。最大値をとる規則は L79/L80） |
| 脅威（リスク値の要素として） | 起こりやすさ |
| 脆弱性（リスク値の要素として） | 残った弱点 |
| リスクレベル | リスクマトリックスの交わるマスが表す、大きさの段階 |
| リスクマトリックス | 発生のしやすさと影響の大きさを縦横にとった表 |
| リスク源 | リスクを生み出すもとになるもの |
| リスク所有者 | そのリスクの責任者（対応の責任と権限をもつ人） |
| 定性的分析 / 定量的分析 | 定性的＝高・中・低の言葉で測る／定量的＝金額や点数の数値で測る |
| リスク忌避 / リスク選好 | 忌避＝リスクを避けたがる姿勢／選好＝取りに行く姿勢。基準の厳しさに表れる |

**読み上げの言い方の固定**: 式は必ず「重要度、かける、脅威、かける、脆弱性」と読む（記号「×」を
「ばつ」「かけ」と揺らさない）。既に `sg-L80-risk-value.md` も同じ言い方なので、L90 もここに揃える。

## 範囲の切り分けメモ

- **リスク対応（回避・共有・保有・低減）と残留リスクは語らない** → L25 が主担当。
  P10（リスク評価）は「基準を超えたものから順に優先順位を付ける」までで止め、
  対応策の選択には一切踏み込まない（最後の1文で次回に渡すだけ）
- **しきい値での対応要否の判定は L80**（科目B）。この回は「リスク基準と比べる」までにして
  「しきい値」という語は出さない
- リスク源は用語のみ（P5 で一言）。深掘りしない
- 重要度＝3特性の最大値をとる規則は L79/L80 の担当。ここでは「資産の価値」までにする
- 情報資産・脅威・脆弱性の言い方は `sg-L2-asset-threat-vuln.md` の表に、
  年間予想損失額・得点法は `sg-L23-asset-classification.md` P8 に揃えた（P6 で回収するだけ）
- クラウドサービスの可用性評価への応用は L90

## 原稿（字幕＝読み上げテキスト。1文＝1セグメント＝字幕1枚）

### s02 導入：すべては守れない（custom：左テキスト＋右イラスト mgmt-balance-risk.png）
1. 今回は、リスクの大きさを測って順位をつける、リスクアセスメントを学びます。
2. リスクは数え切れないほどあり、すべてに同じだけ手をかけられません。
3. だから、洗い出し、測り、順位を付けるという手順を踏みます。

### s03 3つの段階（flow：特定→分析→評価）★背骨
1. リスクアセスメントは、三つの段階で進みます。
2. まず、どんなリスクがあるかを洗い出すリスク特定です。
3. 次に、その大きさを見積もるリスク分析です。
4. 最後に、基準と比べて優先順位を決めるリスク評価です。

### s04 測る前に物差しを決める（custom：キーワード見出し＋忌避↔選好バー）
1. 三つの段階に入る前に、測るための物差しを決めます。
2. どこから上を問題とするかを定めた、リスク基準です。
3. どこまで受け入れるかを示すので、リスク受容基準とも呼びます。
4. 後から基準を動かすと、都合のよい結論になってしまいます。
5. 避けたがる姿勢がリスク忌避、取りに行く姿勢がリスク選好で、基準の厳しさに表れます。

### s05 リスク特定とリスク所有者（bullets ＋ illust person-leader-point.png）
1. 一つ目の段階、リスク特定です。
2. どの資産に、どんな脅威が、どの弱点をついて起きるのかを洗い出します。
3. リスクを生み出すもとになるものを、リスク源と呼びます。
4. そして、リスクごとに責任者となるリスク所有者を決めます。
5. みんなのリスクにすると、結局だれも対応しません。

### s06 分析の測り方は2つ（vs：定性的／定量的・wipe-lightで章転換）
1. 二つ目の段階、リスク分析です。
2. 測り方は二つあり、一つは高・中・低の言葉で測る定性的分析です。
3. もう一つは、金額や点数の数値で測る定量的分析です。
4. 前回の年間予想損失額や得点法は、この定量的分析にあたります。

### s07 リスクマトリックス（custom：3×3グリッド）
1. 定性的分析でよく使うのが、リスクマトリックスです。
2. 発生のしやすさと、影響の大きさを縦横にとった表です。
3. 交わるマスが表す大きさの段階を、リスクレベルといいます。
4. 起きやすくて影響も大きい右上が、最も高いリスクレベルです。

### s08 リスク値の式（custom：式ドン）★主担当
1. 定量的に測るときの、代表的な式を見ましょう。
2. リスク値は、重要度、かける、脅威、かける、脆弱性で求めます。
3. 重要度は資産の価値、脅威は起こりやすさ、脆弱性は残った弱点です。
4. 掛け算なので、どれか一つが小さければリスク値も小さくなります。

### s09 【計算ワーク】手を動かす（custom：台帳1行→穴埋め式→答え）
1. では、実際に手を動かして計算してみましょう。
2. 顧客名簿は、重要度が3、脅威が2、脆弱性が2と評価されました。
3. 三つを掛けると、3かける2かける2で、12になります。（考える間 1.5秒）
4. 表から三つ拾って掛けるだけ、というのが計算の中身です。

### s10 リスク評価：優先順位を付ける（custom：降順バー＋順位バッジ）
1. 三つ目の段階、リスク評価です。
2. 分析で出た大きさを、最初に決めたリスク基準と比べます。
3. 基準を超えたものから順に、対応の優先順位を付けます。
4. どう対応するかは、次回のリスク対応で学びます。

### s11 クイズ幕間（SectionTitle・共通音声 QUIZ_INTRO_SEG）
1. ここまで学んだことを、クイズ形式で確認していきましょう。

### s12 クイズ①（3段階の並び順・正解B）
1. ここで問題です。
2. リスクアセスメントの三つの段階は、どの順番で進めるでしょうか。
3. （考える間 1.8秒）正解は、特定、分析、評価の順です。

### s13 クイズ②（基準を先に決める理由・正解A）
1. 次の問題です。
2. リスク基準を、測る前に決めておくのはなぜでしょうか。
3. （考える間 1.8秒）正解は、後から都合よく基準を変えないためです。

### s14 クイズ③（マトリックスの読み取り・正解B）
1. 最後の問題です。
2. リスクマトリックスで、リスクレベルが最も高くなるのはどれでしょうか。
3. （考える間 1.8秒）正解は、起きやすく影響も大きいものです。

### s15 まとめ（summary・wipeで転換・共通音声 OUTRO_SEG）
1. リスクアセスメントは、特定、分析、評価の三段階で進めます。
2. 測る前に、判断の物差しとなるリスク基準を決めておきます。
3. リスク値は、重要度、かける、脅威、かける、脆弱性で求めます。
4. 今回のレッスンはここまでです。お疲れさまでした！（共通音声）
