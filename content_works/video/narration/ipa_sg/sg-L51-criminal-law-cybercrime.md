## この回の位置づけ

第6章（法務）の5本目。L48（不正アクセス禁止法）の**直後**に置き、
**「入るところまでが不正アクセス禁止法、その先の行為が刑法」**という分担で始める。

背骨は発注書の一言そのまま — **四つの動詞（作る・だます・壊す・偽る）で五つの罪を引く**。
罪名が長く似ているのがこの範囲の難所なので、「何をしたか」＝動詞から罪名へ辿れる形に固定した。

| 動詞 | 罪 |
|---|---|
| 作る | 不正指令電磁的記録に関する罪（通称 ウイルス作成罪） |
| だます | 電子計算機使用詐欺罪 |
| 壊す | 電子計算機損壊等業務妨害罪 |
| 偽る | 電磁的記録不正作出及び供用罪 ／ 支払用カード電磁的記録不正作出等罪 |

### L48（不正アクセス禁止法）との境目

L48 の narration と突合済み。**L48 が扱ったもの（不正アクセス行為の二つの型・ネットワーク越しの
要件・アクセス制御機能・助長する行為）には一切戻らない**。この回で L48 に触れるのは2箇所だけ:

- s02（導入）: 「前回は、他人のIDで勝手にログインする行為を学びました」と受けて分担を宣言する
- s10（★抽象→具体）: ログイン＝不正アクセス禁止法／その先の送金＝刑法、と1つの場面で線を引く

**罰則は「罰せられます」「罪になります」までにとどめ、刑名・年数・金額は出さない**
（L47・L48・L49・L50 と揃えた方針。刑法改正で刑名の呼び方が動いており、教材に揺れを
持ち込まないため。試験で問われるのは「行為と罪名の対応」「実行前でも成立する」の側）。

### 扱わない（発注書どおり）

- 不正アクセス行為そのもの → L48（上記の2箇所で分担を語るだけ。二つの型・要件には戻らない）
- DoS攻撃・マルウェアの手口 → L5・L12（s07 で「DoS攻撃もこの罪に当たる」と1文つなぐだけ）
- 電子署名法・特定電子メール法 → L52（語も出さない）
- 民事上の損害賠償 → 刑事罰の回と割り切り、触れない
- 個人情報の漏えい・知的財産権 → L47・L49・L50（語も出さない）
- 暗記カードなど他機能への誘導文は書かない（動画は1本で完結させる決まり）

## 用語の呼称（この回が正）

| 用語 | この回での言い方 |
|---|---|
| 不正指令電磁的記録に関する罪 | 通称 **ウイルス作成罪**。不正指令電磁的記録＝いわゆるマルウェア（使う人の意図に反して動くよう作られたプログラム）。**作る・他人に渡す・正当な理由なく持っておく**のすべてが対象で、**実際に動かして被害が出る前から成立する** |
| 電子計算機使用詐欺罪 | コンピュータにうその情報や不正な指令を与えて、お金や財産上の利益を手に入れる罪。**人ではなく機械をだます**のが特徴（例: 他人のネットバンキングで自分の口座へ送金） |
| 電子計算機損壊等業務妨害罪 | コンピュータやデータを壊して**業務を妨害する**罪。狙いが「業務を止めること」の側にあるのが詐欺の罪との違い。データを消して受注できなくする／DoS攻撃で止める、が典型 |
| 電磁的記録不正作出及び供用罪 | **紙の文書偽造のデジタル版**。権限がないのに証明になるデータを作り変えるのが**不正作出**、そのデータを使うのが**供用** |
| 支払用カード電磁的記録不正作出等罪 | クレジットカードなどの**磁気やICの情報**が対象。読み取った情報から複製カードを作ると成立し、**持っているだけでも**罰せられる。手口としてはスキミング |
| 刑法と不正アクセス禁止法の分担 | **入るところまでが不正アクセス禁止法、その先の行為が刑法** |

## 読みの例外（音声だけ仮名書き・字幕と画面は漢字/英字）

`references/narration.md` の例外規定。**この回は「作」「使」「壊」の3字が罪名の熟語
（作成罪・作出・使用詐欺罪・損壊）として何度も出る**ので、同じ漢字の和語動詞は
確認するまでもなく最初から仮名書きにしている（sg-L38「通す」と同型の予防）。

| 字幕・画面表記 | 音声用テキスト | 理由 |
|---|---|---|
| 作る／作った／作り／作ること | つくる／つくった／つくり／つくること | 同回に「作成罪」「作出」（さくせい・さくしゅつ）が頻出 |
| 作り変える | つくりかえる | 同上 |
| 使う／使った | つかう／つかった | 同回に「使用詐欺罪」（しよう）が頻出 |
| 壊す／壊して | こわす／こわして | 同回に「損壊」（そんかい）が頻出 |
| 偽る／偽の | いつわる／にせの | 同回に「偽造」（ぎぞう）が出る |
| 作出 | さくしゅつ | 稀な語で読みが揺れやすい |
| 支払用 | しはらいよう | 送り仮名なしの「支払」＋「用」で読みが揺れる |
| 等（罪名の中） | とう | 「損壊等」「不正作出等」が「〜など」と読まれるのを防ぐ |
| 及び（罪名の中） | および | 同上 |
| ID | アイディー | L48 に揃える |
| IC | アイシー | 英字のままだと読みが揺れる |
| DoS | ドス | 確認済みの読み（references/narration.md の辞書） |

字幕のルビは **DoS（ドス）の初出1回だけ**（1字ずつ読まない略語なので画面から読み方を学べるようにする）。

## ナレーション原稿

### s02 導入 — 入るまでと、その先
1. 前回は、他人のIDで勝手にログインする行為を学びました。
2. では、入り込んだ先でデータを書き換えたら、どうなるでしょうか。
3. 入るところまでが不正アクセス禁止法、その先の行為は刑法です。
4. 今回は、サイバー犯罪を罰する刑法の罪を見ていきます。

### s03 四つの動詞で引く
1. 刑法には、コンピュータに関わる罪がいくつも置かれています。
2. 覚え方は簡単で、四つの動詞にまとめられます。
3. 悪いプログラムを作る、そしてコンピュータをだます。
4. システムを壊す、そしてデータやカードを偽る。
5. この四つの動詞から、五つの罪を引けるようにします。

### s04 ウイルス作成罪
1. 一つ目は、不正指令電磁的記録に関する罪です。
2. 通称、ウイルス作成罪と呼ばれます。
3. 不正指令電磁的記録とは、いわゆるマルウェアのことです。
4. 使う人の意図に反して動くよう作られたプログラムを指します。
5. これを世に出す行為が、刑法で罰せられます。

### s05 作る・渡す・持つ
1. この罪で大事なのは、罰せられる範囲の広さです。
2. マルウェアを作ることは、もちろん罪になります。
3. 他人に渡すことも、正当な理由なく持っておくことも同じです。
4. しかも、実際に動かして被害が出る前から成立します。
5. 手元に置いているだけで罪になる。ここがよく問われます。

### s06 電子計算機使用詐欺罪（wipe-light）
1. 二つ目は、電子計算機使用詐欺罪です。
2. コンピュータに、うその情報や不正な指令を与えます。
3. そうして、お金や財産上の利益を手に入れる罪です。
4. たとえば、他人のネットバンキングで自分の口座へ送金する。
5. 人ではなく機械をだまして利益を得る。ここが特徴です。

### s07 電子計算機損壊等業務妨害罪
1. 三つ目は、電子計算機損壊等業務妨害罪です。
2. コンピュータやデータを壊して、業務を妨害する罪です。
3. 顧客データを消して、受注ができなくなる。これが典型です。
4. 大量のデータを送りつけるDoS（ドス）攻撃も、この罪です。
5. 狙いは業務を止めること。そこが、詐欺の罪との違いです。

### s08 電磁的記録不正作出及び供用罪
1. 四つ目は、電磁的記録不正作出及び供用罪です。
2. 紙の文書を偽造する罪の、デジタル版だと考えてください。
3. 権限がないのに、証明になるデータを勝手に作り変える。
4. これが不正作出で、そのデータを使うことが供用です。
5. 社員証や証明書のデータを書き換える行為が当たります。

### s09 支払用カード電磁的記録不正作出等罪
1. 五つ目は、支払用カード電磁的記録不正作出等罪です。
2. クレジットカードなどの、磁気やICの情報が対象です。
3. 読み取った情報から複製のカードを作ると、この罪です。
4. 手口としては、スキミングがよく知られています。
5. 作るだけでなく、持っているだけでも罰せられます。

### s10 ★抽象→具体：一つの場面に、二つの法律
1. 最後に、一つの場面で整理してみましょう。
2. 他人のIDで、銀行のシステムにログインしたとします。
3. さらに残高のデータを書き換え、自分の口座へ送金しました。
4. ログインしたところまでが、不正アクセス禁止法です。
5. その先の送金は、電子計算機使用詐欺罪に当たります。
6. 入る行為と、その先の行為。分けて覚えるのがコツです。
