## 原稿（読み上げ＝字幕）

**P2 なぜパスワードが狙われるのか**
1. 今回は、パスワードそのものを狙う攻撃について学びます。
2. IDとパスワードは、あなたの情報を守る玄関の鍵です。
3. 鍵さえ手に入れば、攻撃者は正規の利用者として入れてしまいます。
4. 破り方は大きく四通りあり、狙われ方によって効く守り方が変わります。

**P3 辞書攻撃**
1. 一つ目は、辞書攻撃です。
2. よく使われる単語やありがちな文字列を、辞書のように並べて試します。
3. 英単語そのものや、単純な数字の並び、名前や誕生日が代表例です。
4. 複雑さよりも、ありがちであることのほうが危ないのです。

**P4 総当たり（ブルートフォース）攻撃**
1. 二つ目は、総当たり攻撃、ブルートフォース攻撃です。
2. 考えられる文字の組み合わせを、片端から機械的に試します。
3. 英字と数字の四桁なら、およそ百六十八万通りしかありません。
4. これが八桁になると、組み合わせは約二兆八千億通りに跳ね上がります。
5. 桁数が増えるほど、総当たりは現実的でなくなります。

**P5 リバースブルートフォース攻撃**
1. 三つ目は、リバースブルートフォース攻撃です。
2. ふつうの総当たりは、IDを固定してパスワードを次々に変えます。
3. 同じIDで失敗が続くため、アカウントロックで止められます。
4. リバースブルートフォースは、その逆で、パスワードを固定します。
5. よくあるパスワードを一つ決め、IDのほうを次々に変えていきます。
6. 一つのIDあたりの失敗は一回だけなので、ロックをすり抜けてしまいます。

**P6 パスワードリスト攻撃**
1. 四つ目は、パスワードリスト攻撃です。
2. クレデンシャルスタッフィングとも呼ばれます。
3. まず、どこかのサービスからIDとパスワードの組が流出します。
4. 攻撃者はその一覧を手に入れ、別のサービスでそのまま試します。
5. 同じ組み合わせを使い回していれば、一発でログインされてしまいます。

**P7 使い回しが致命傷になる**
1. リスト攻撃で狙われるのは、パスワードの使い回しです。
2. 一つの鍵で、いくつもの扉が開いてしまう状態だからです。
3. 一か所の流出が、そのまま他のサービスの被害に直結します。
4. どれだけ複雑なパスワードでも、使い回した時点で弱点になります。

**P8 4つの違いの整理**
1. ここまでの四つを、何を固定して何を変えるかで整理します。
2. 辞書攻撃と総当たり攻撃は、IDを固定してパスワードを変えます。
3. リバースブルートフォースは、パスワードを固定してIDを変えます。
4. パスワードリスト攻撃は、漏れた組み合わせをそのまま使います。
5. どれを狙われているかで、効く守り方が変わります。

**P10 クイズ1**
1. ここで問題です。
2. アカウントロックで止めにくいのは、どちらの攻撃でしょうか。
3. 正解は、リバースブルートフォース攻撃です。（考える間 1.8秒）

**P11 クイズ2**
1. 次の問題です。
2. よく使われる語を並べて試す攻撃を、何と呼ぶでしょうか。
3. 正解は、辞書攻撃です。（考える間 1.8秒）

**P12 クイズ3**
1. 最後の問題です。
2. パスワードリスト攻撃を防ぐうえで、いちばん大切なことは何でしょうか。
3. 正解は、パスワードを使い回さないことです。（考える間 1.8秒）

**P13 まとめ**
1. 辞書攻撃と総当たり攻撃は、IDを固定してパスワードを試します。
2. リバースブルートフォースは、IDを変えてロックをすり抜けます。
3. リスト攻撃は、使い回したパスワードを一発で突破します。
4. （共通音声 OUTRO_SEG）
