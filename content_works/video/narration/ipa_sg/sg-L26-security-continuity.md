## 原稿（字幕＝読み上げテキスト。1文＝1セグメント＝字幕1枚）

### s02 導入：事故は起きる前提（custom：左イラスト mgmt-bcp.png ＋右テキスト）
1. 今回は、情報セキュリティ継続について学びます。
2. どれだけ対策をしても、事故が起きる可能性はゼロにはなりません。
3. 起きてしまった時に業務を止めない、そして元に戻せる準備が必要です。
4. 会社全体で事業を続ける計画は、のちの経営の章で学びます。

### s03 緊急事態の区分（custom：アイコン3カード）
1. まず、緊急事態には種類があります。
2. 地震や火災などの災害、機器やシステムの障害、そしてサイバー攻撃です。
3. 何が起きたかによって、呼ぶ相手も打つ手も変わってきます。
4. だから、あらかじめ区分を決めておくことが、初動の速さになります。

### s04 緊急時対応計画（custom：キーワード見出し＋右イラスト person-leader-point.png）
1. 事故の直後にどう動くかを、事前に決めておく計画があります。
2. これを緊急時対応計画、またはコンティンジェンシー計画と呼びます。
3. 誰が、何を、どの順でやるかを、あらかじめ文書にしておきます。
4. 慌てている場面で考えるのでは、間に合わないからです。

### s05 応急の対応と復旧は別の段階（custom：横帯2フェーズ）★核心
1. ここで押さえたいのが、対応と復旧は別の段階だということです。
2. 事故の直後は、被害を広げないための応急の対応をします。
3. 業務は、手作業などの代わりの手段で何とか続けます。
4. そのあと、元の状態に戻していくのが復旧です。
5. この二つを分けるのが、計画づくりの軸になります。

### s06 具体場面：受注システムが止まった朝（custom：左イラスト scene-incident.png ＋時刻つき3行）★抽象→具体
1. 具体的な場面で見てみましょう。
2. 月曜の朝、受注システムが止まり、注文が受けられなくなりました。
3. 応急の対応として、注文を電話と紙の伝票で受け付けます。
4. 並行して原因を調べ、午後にシステムを元へ戻しました。

### s07 災害復旧と障害復旧（vs・wipe-lightで章転換）
1. 復旧の計画は、原因の大きさで二通りに分けて考えます。
2. 一つは災害復旧で、地震や火災で拠点ごとやられた場合の備えです。
3. 建物や設備も含めて、離れた場所で立て直すことまで考えます。
4. もう一つは障害復旧で、機器の故障や不具合への備えです。
5. 部品の交換やデータの復元で、短い時間で戻します。

### s08 被害状況の調査（custom：縦3ステップ＋注意帯）
1. 戻す前に、必ずやることがあります。
2. 何がどこまでやられたのかを、調べて把握することです。
3. まず、記録が上書きされないように、ログをそのまま残します。
4. そのうえで、影響が及んだ範囲と原因を突き止めます。
5. 順番を誤って先に戻すと、原因が分からず被害を広げてしまいます。

### s09 バックアップによる対策（custom：左イラスト icon-backup.png ＋キーワード見出し）
1. 戻すために欠かせないのが、データの控えを取っておくことです。
2. これが、バックアップによる対策です。
3. 大事な情報の写しを、別の場所にも置いておきます。
4. 取り方にはいくつかの方式があり、そこはのちの回で学びます。

### s10 取ってあるだけでは対策にならない（custom：✗／○の2枚カード）
1. 大事なのは、取ってあるだけでは対策にならない点です。
2. いざ戻そうとしたら壊れていた、という話は珍しくありません。
3. 実際に戻せるかを、ときどき試して確かめておきます。
4. 同じ部屋に置いた控えは、火事や水害で一緒に失われます。
5. 控えは、離れた場所にも分けて保管します。

1. ここまで学んだことを、クイズ形式で確認していきましょう。

### s12 クイズ①（緊急時対応計画・正解A）
1. ここで問題です。
2. 緊急時対応計画は、何のために決めておく計画でしょうか。
3. （考える間 1.8秒）正解は、事故の直後の動き方を決めておくためです。

### s13 クイズ②（応急の対応と復旧の区別・正解B）
1. 次の問題です。
2. 注文を紙の伝票で受け付けるのは、どちらの段階でしょうか。
3. （考える間 1.8秒）正解は、業務を続けるための応急の対応です。

### s14 クイズ③（戻せて初めて対策・正解A）
1. 最後の問題です。
2. バックアップを取ったあとに、確かめておくべきことは何でしょうか。
3. （考える間 1.8秒）正解は、実際に元へ戻せるかどうかです。

### s15 まとめ（summary・wipeで転換・共通音声 OUTRO_SEG）
1. 緊急事態は、災害、障害、攻撃に区分して備えます。
2. 事故の直後の応急の対応と、元に戻す復旧は、分けて計画します。
3. バックアップは、実際に戻せることを確かめて初めて対策になります。
4. 今回のレッスンはここまでです。お疲れさまでした！（共通音声）
