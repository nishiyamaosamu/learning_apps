# SG-L53 労働・取引関連法規

- **一言で**: 「誰の指示で働くか」「何を約束して発注するか」— 契約の形で責任の所在が変わる
- **シラバス**: 法務#3「労働関連・取引関連法規」全部
- **主担当**: なし
- **依存**: なし

## 扱う

| 用語・論点 | 何を語るか |
|---|---|
| 労働基準法と就業規則 | 労働条件の最低基準。セキュリティ関連の服務規律・懲戒も就業規則に書くから効く、とL27の規程類に接続 |
| 労働者派遣法 | 雇用は派遣元・指揮命令は派遣先、という分離が全て。指揮命令の矢印を図にして固める |
| 準委任契約／請負契約 | 作業の遂行を頼むか、完成物を約束させるか。指揮命令できるか・完成責任があるかの対比表で（偽装請負にも一言） |
| 守秘契約（NDA） | 取引で知った秘密を漏らさない約束。営業秘密（L47）・誓約書（L34）とつながる実務の要 |
| ソフトウェア使用許諾契約とコピーレフト | 買ったのは「使う権利」。ボリュームライセンス、そしてコピーレフト（改変物にも同じ自由を要求するライセンス）まで |
| ソフトウェア開発委託モデル契約 | 発注側とベンダの役割分担・秘密保持・検収を定める雛形。要件定義は準委任・開発は請負が典型と一言 |

## 扱わない
- 著作権法そのもの → L47（説明済み、参照のみ）
- 秘密保持契約の人的対策としての運用 → L34（説明済み、参照のみ）
- 委託先の管理・監督の実務 → L89（科目B）
- RFP・調達の流れ → L73

## 確認パート
- 通常クイズ2〜3問
- 出しどころ: 派遣と請負の指揮命令の違い（定番）／完成責任があるのはどの契約か
