# SG-L13 攻撃の手順とビジネス化

- **一言で**: 攻撃は一発勝負ではなく段取りのある工程 — しかも今は分業された「商売」になっている
- **シラバス**: 情報セキュリティ#1「攻撃の動機」「サイバー攻撃手法」（攻撃の準備・RaaS ほか）
- **主担当**: なし。不正の動機の心理面の正は L6
- **依存**: L6〜L12 の後（第1章の締めとして、個々の攻撃を1本の流れに並べ直す回）

## 扱う

| 用語・論点 | 何を語るか |
|---|---|
| サイバーキルチェーン | 偵察→侵入→内部活動→目的実行、という段階の流れ。**この回の背骨**として1枚の図に |
| フットプリンティング／ポートスキャン | 攻撃前の下調べ。公開情報だけでもかなり分かる |
| ラテラルムーブメント | 侵入後、内部を横に移動して権限と情報を広げる。「1台の感染」で終わらない理由 |
| どの段階でも止められる | 段階のどこか1つを断てば被害は止まる（多層防御＝L1 の考え方に接続） |
| RaaS | ランサムウェアが道具として売られ、技術のない者でも攻撃できる |
| リークサイト | 盗んだ情報を公開する場。二重脅迫（L5）を成り立たせる仕組み |
| ハクティビズム／サイバーテロリズム | 金銭以外の動機（主張・破壊）。攻撃者像の幅を示す |

## 扱わない
- 不正のトライアングル・攻撃者の種類・ダークウェブ → L6
- 個々の攻撃手法の詳細 → L7〜L12
- ペネトレーションテスト・脆弱性診断（守る側の疑似攻撃）→ L33
- CSIRT・インシデント対応の手順 → L30

## 確認パート
- 通常クイズ2〜3問
- 出しどころ: ラテラルムーブメントを踏まえた「1台の感染を軽く見てはいけない」理由／RaaS が意味すること
