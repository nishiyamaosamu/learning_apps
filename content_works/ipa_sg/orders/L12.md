# SG-L12 DoS攻撃と標的型攻撃

- **一言で**: 「みんなを止める」攻撃と「あなただけを狙う」攻撃 — 広く浅くと、狭く深く
- **シラバス**: 情報セキュリティ#1「サイバー攻撃手法」（DoS・標的型・ゼロデイ）
- **主担当**: なし
- **依存**: L5 の後（ボットネットが DDoS の道具として繋がる）

## 扱う

| 用語・論点 | 何を語るか |
|---|---|
| DoS攻撃 | 大量の要求でサービスを止める。壊さずに「使えなくする」＝可用性への攻撃 |
| DDoS攻撃 | 多数の踏み台から一斉に。**遮断が難しい理由**（正規の利用者と見分けがつかない）まで |
| 標的型攻撃 | 特定の組織だけを狙い、業務メールに紛れて入る。ばらまき型との違いを対比で |
| APT（持続的標的型） | 侵入後に長く潜む。「入られた前提」の発想へ繋げる |
| 水飲み場型攻撃 | 標的がよく見るサイトを改ざんして待ち伏せる |
| ゼロデイ攻撃 | 修正プログラムが出る前に突かれる。パッチ運用だけでは間に合わない |
| 機能の悪用 | 正規の機能をそのまま悪用する攻撃（脆弱性がなくても成立する） |

## 扱わない
- ボットネット・C&Cサーバの仕組み → L5
- ラテラルムーブメント・サイバーキルチェーン → L13
- ファイアウォール・IDS/IPS・WAF などの防御 → L38・L39
- パッチ適用基準・脆弱性管理 → L37

## 確認パート
- 通常クイズ2〜3問
- 出しどころ: DDoS が単純なDoSより防ぎにくい理由／標的型攻撃が普通のメール対策をすり抜ける理由
