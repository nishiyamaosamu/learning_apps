# SG-L29 ISMS②：管理策と認証制度

- **一言で**: 具体的に何をやるかのカタログ（管理策）と、外部に証明する仕組み（認証）
- **シラバス**: 情報セキュリティ#2「情報セキュリティマネジメントシステム（ISMS）」の後半（管理策・有効性・適合性評価制度・ガバナンス）
- **主担当**: なし（この回の管理策4区分を L81（科目B）が参照する）
- **依存**: L28 の後（27001（要求事項）に対する27002（実践の手引）、という対で始めるため）

## 扱う

| 用語・論点 | 何を語るか |
|---|---|
| JIS Q 27002と管理策 | 27001が「何を満たすか」、27002が「具体的にどうやるか」のカタログ。管理目的と有効性（効いているか）の言葉もここで |
| 管理策の4区分 | 組織的・人的・物理的・技術的。第4章（L34〜L41）がこの区分どおりに進む予告編として使う |
| 管理策タイプ | 予防・検知・対応・復旧。「事前に防ぐ／起きたことに気づく／動く／戻す」の時間軸で整理 |
| ISMS適合性評価制度・ISMS認証 | 第三者が審査して認証する制度。取引先に「仕組みがある」ことを示せるのが価値 |
| 情報セキュリティガバナンス（JIS Q 27014） | 経営層がISMSを方向づけ・モニタリングする枠組み。ISMS（管理者の仕事）との層の違いを一言で |

## 扱わない
- マネジメントシステムの要求事項（適用範囲・リーダーシップ・内部監査など）→ L28
- 個々の管理策の中身（アクセス制御・ログ管理・物理対策など）→ 第4章 L34〜L41
- ISMAP（政府調達のクラウド評価制度）→ L31
- プライバシーマーク・JIS Q 15001 → L50
- 管理策の4区分から対応策を選ぶケース演習 → L81（科目B）
