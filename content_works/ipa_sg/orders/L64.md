# SG-L64 通信サービスとVPN

- **一言で**: 会社の拠点と拠点、社員と会社をつなぐ「回線の買い方」のカタログ
- **シラバス**: 中分類5「データ通信と制御（伝送方式と回線）」「ネットワーク応用（イントラネット・エクストラネット、通信サービス）」
- **主担当**: なし（VPNの暗号化トンネルとしての説明は L45 が済み。この回はサービスの種類の側）
- **依存**: L45 の後が望ましい（VPNという言葉を既習として種類の話に進める）

## 扱う

| 用語・論点 | 何を語るか |
|---|---|
| 回線の地図：専用線・パケット交換・FTTH | 1社占有の専用線から、みんなで分け合うパケット交換へ。FTTHは光の足回り、という歴史込みの地図 |
| IP-VPN・インターネットVPN・広域Ethernet | 拠点間をつなぐ3つの選び方。通信事業者の閉域網か、インターネット上の暗号化トンネル（L45）か。安全性とコストの対比表で |
| 移動体通信（LTE・5G）とテザリング | 持ち歩く回線。テザリングは便利だが、会社のルールで許可制になっている理由（管理外の出口になる）まで |
| IP電話（VoIP） | 音声もパケットで運ぶ。電話網とネットワークが同じ土俵になった、という位置づけだけ |
| ベストエフォート | 「最大○Gbps」は保証ではない。SLA（L67）で保証を買う世界との対比で予告 |
| EC・EDI | 企業間の商取引もネットワークの上。EDIは「取引データを決まった形式で交換する」の一言で |

## 扱わない
- IPsec・VPNの暗号化の仕組み → L42・L45（説明済み、参照のみ）
- 無線LAN → L65
- 公衆回線・回線交換の歴史的詳細 → 暗記カード（地図で名前だけ）
- SLA・サービスレベル → L67（第8章）
