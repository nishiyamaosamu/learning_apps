# SG-L67 サービスマネジメント①：SLAとサービスレベル管理

- **一言で**: 「ちゃんと動く」を数字で約束する — SLAの読み方と達成率の測り方
- **シラバス**: 中分類7「SLA」「サービスの計画」「サービスカタログ管理」「事業関係管理・サービスレベル管理・供給者管理」「需要管理」「パフォーマンス評価」
- **主担当**: なし（サービスマネジメント3部作の1本目。可用性・継続はL69、運用はL68）
- **依存**: なし（ベストエフォート（L64）との対比から入ると滑らかだが、強い依存ではない）

## 扱う

| 用語・論点 | 何を語るか |
|---|---|
| SLA（サービスレベル合意書） | サービスの品質を数値で約束する文書。提供者と利用者の期待ずれを防ぐのが目的 |
| サービスレベル目標 | 稼働率99.9%・応答3秒以内など測れる目標にする（R8問9の題材）。稼働率の定義はL56を参照 |
| 【計算ワーク】目標達成率 | R7問9の型を1問実演。停止時間から稼働率を計算して目標と比べる（反復ドリルは問題集） |
| サービスカタログ | 提供中のサービスの一覧。「何を頼めるか」を利用者に見せる窓口 |
| 関係管理の地図（1シーン） | 事業関係管理（顧客と）・供給者管理（外部委託先と）・需要管理（利用の増減を読む）を一言ずつ |
| パフォーマンス評価とサービスの報告 | 目標に対する実績を定期的に測って報告する。約束は「測って見せて」初めて回る、で締める |

## 扱わない
- サービスデスク・インシデント管理・問題管理 → L68
- サービス可用性管理・継続管理・RTO/RPO → L69
- 稼働率・MTBF/MTTRの定義 → L56（説明済み、参照のみ）
- 委託先管理のケース演習 → L89（科目B）

## 確認パート
- 通常クイズ2〜3問（計算ワークとは別枠）
- 出しどころ: SLAに書くべき目標の性質（測れること、R8問9の型）／需要管理・供給者管理の役割判別
