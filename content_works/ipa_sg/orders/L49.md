# SG-L49 個人情報保護法①：保護のルール

- **一言で**: 「個人情報」の範囲は思ったより広い — 集めた企業に課される義務の基本セット
- **シラバス**: 法務#2「個人情報保護法」の前半（定義・事業者の義務・第三者提供・個人情報保護委員会）
- **主担当**: なし（この回の定義を L50・L92 が前提にする）
- **依存**: なし

## 扱う

| 用語・論点 | 何を語るか |
|---|---|
| 個人情報の定義 | **生存する個人**を識別できる情報（R6問7の題材）。単体で特定できなくても、他の情報と容易に照合して特定できれば該当する、まで |
| 個人情報取扱事業者 | 個人情報をデータベース化して事業に使う者はほぼ全事業者が該当。「うちは小さいから関係ない」は通らない |
| 要配慮個人情報 | 人種・信条・病歴・犯罪歴など。取得自体に本人の同意が要る、通常より厳しい扱い |
| 安全管理措置 | 漏らさないよう管理する義務。組織的・人的・物理的・技術的の4本柱で、L29の管理策4区分と同じ骨格と気づかせる |
| 第三者提供とオプトイン／オプトアウト | 原則は事前同意（オプトイン）。届け出れば停止申出方式（オプトアウト）も使えるが、要配慮個人情報には使えない |
| 個人情報保護委員会 | 監督官庁。報告徴収・立入検査・命令の権限。漏えい時の報告先でもある |

## 扱わない
- 匿名加工情報・仮名加工情報・匿名加工の手法 → L50
- マイナンバー法・プライバシーマーク・GDPR・PIA → L50
- 漏えいインシデント発生時の対応手順 → L30（参照のみ）
- 匿名加工のケース演習 → L92（科目B）

## 確認パート
- 通常クイズ2〜3問
- 出しどころ: 個人情報に該当するかの判別（R6問7の型。生存要件・容易照合性）／オプトアウトが使えないケース
