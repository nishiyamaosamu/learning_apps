# SG-L48 サイバーセキュリティ基本法と不正アクセス禁止法

- **一言で**: 国全体の方針を定める法と、「入ってはいけない」を定める法
- **シラバス**: 法務#2「サイバーセキュリティ基本法」「不正アクセス禁止法」全部
- **主担当**: なし（NISC・戦略本部の組織側は L31 が説明済み。この回は法的根拠の側から再訪する）
- **依存**: L31 の後が望ましい（「L31で見た司令塔の根拠法」と接続できる。強い依存ではない）

## 扱う

| 用語・論点 | 何を語るか |
|---|---|
| サイバーセキュリティ基本法 | 国・自治体・事業者・国民の責務を定めた基本法。サイバーセキュリティ戦略とサイバーセキュリティ協議会（官民の情報共有）をここで |
| 不正アクセス行為とは | 他人のID・パスワードでのなりすましログインと、脆弱性を突いた侵入。**ネットワーク越し**が要件、まで正確に |
| アクセス制御機能 | この法律は「アクセス制御機能を備えたコンピュータ」を守る。パスワードすら無い機器への行為は本法の対象外になる、という構造 |
| 不正アクセス行為を助長する行為 | 他人のパスワードを無断で第三者に教える・売るのも罪。実行しなくても罰される |
| 罰則と身近な事例 | 同僚のIDでログインして閲覧しただけでも違反。被害ゼロでも成立する、を事例で |

## 扱わない
- NISC・サイバーセキュリティ戦略本部の役割 → L31（説明済み、参照のみ）
- ウイルス作成罪・電子計算機使用詐欺罪など刑法の罪 → L51（「侵入した先で何をしたかは刑法」と分担を予告）
- パスワードを守る技術側の対策 → L18（参照のみ）
- 個人情報を盗まれた場合の扱い → L49

## 確認パート
- 通常クイズ2〜3問
- 出しどころ: 不正アクセス禁止法に触れる行為の判別（パスワードを教える行為を含む）／アクセス制御機能の要件
