# SG-L41 物理的セキュリティ対策

- **一言で**: サイバー対策も物理で破られたら終わり — 場所・人の出入り・設備・媒体を守る
- **シラバス**: 情報セキュリティ#4「物理的セキュリティ対策」全部（RASIS・RAS技術・ミラーリングを除く。下記参照）
- **主担当**: なし（RASISの正は L56（第7章）。この回では設備の多重化を「止めない工夫」とだけ言い、指標名に踏み込まない）
- **依存**: なし（第4章の締め。L29の「物理的管理策」の区分を回収する）

## 扱う

| 用語・論点 | 何を語るか |
|---|---|
| セキュリティゾーニング | 誰でも入れる区域から重要区域まで段階を分け、奥ほど厳しくする。ビルの受付→執務室→サーバ室の絵で |
| 入退室管理（アンチパスバック・インターロック） | 共連れ・使い回しを仕組みで防ぐ（R5問2の題材）。「入った記録がない人は出られない」（アンチパスバック）、二重扉（インターロック） |
| 監視カメラ・施錠管理 | 検知と抑止の基本。カメラは「見られている」だけで内部不正の機会（L6）を減らす |
| クリアデスク・クリアスクリーン | 帰るとき机に書類を残さない・離席時に画面をロックする。もっとも安い対策 |
| 設備の対策：UPS・耐震耐火設備・多重化 | 停電・地震・火災でも止めない/壊さないための設備。可用性を物理で支える側 |
| 遠隔バックアップ | 控えを同じ建物に置いたら共倒れ。3-2-1ルール（L35）の「1つは別の場所」を物理側から回収 |
| 記憶媒体の管理と処分 | 持ち出し管理と、捨てるときの完全消去・物理破壊。論理で消すCE（L40）との対で締める |

## 扱わない
- RASIS・RAS技術 → L56（第7章が主担当）、ストレージのミラーリング・多重化の技術詳細 → L57
- USBキー・セキュリティケーブル → 暗記カード
- 入退室管理のケース演習（ゲスト入館証・共連れの穴）→ L82（科目B）
- 媒体・文書管理の点検のケース演習 → L86（科目B）
- バックアップの方式・世代管理 → L59
