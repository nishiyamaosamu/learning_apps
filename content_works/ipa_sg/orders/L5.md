# SG-L5 ランサムウェアとボットネット

- **一言で**: 感染したあと何をされるか — 「金を取られる」ものと「乗っ取られて使われる」もの
- **シラバス**: 情報セキュリティ#1「脅威」〔マルウェア・不正プログラム〕の後半
- **主担当**: なし（マルウェアの分類地図の正は L4）
- **依存**: L4 の後。L4 が「感染のしかたで分ける地図」なので、この回は**目的・被害で分ける**側を担う

## 扱う

| 用語・論点 | 何を語るか |
|---|---|
| ランサムウェア | データを暗号化して身代金を要求する。復旧できても払う判断は別問題 |
| 二重脅迫 | 暗号化に加えて「払わないと公開する」。バックアップがあっても脅せる、が要点 |
| ボット／ボットネット／C&Cサーバ | 乗っ取られた大量の端末が、指令サーバの命令で一斉に動く構造を絵で |
| RAT（遠隔操作型） | 攻撃者が手元で操作する。ボットとの違いは「自動 vs 手動」で一言 |
| 踏み台 | 被害者が加害者になる。自社が攻撃元として名前が出る怖さ |
| バックドア／ルートキット | 再侵入用の裏口と、それを隠す技術。「駆除したはずなのに」の正体 |
| ファイルレスマルウェア | ファイルを置かないので、ファイルを見る検査に映らない |
