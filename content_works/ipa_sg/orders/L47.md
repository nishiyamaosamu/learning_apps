# SG-L47 知的財産権と不正競争防止法

- **一言で**: 会社の「かたち」と「秘密」は法律で守られている — 何をすると侵害になるか
- **シラバス**: 法務#1「知的財産権」「不正競争防止法」全部
- **主担当**: なし（第6章の入口。法務の章の読み方＝「何を守る法か・何をすると違反か」の型をここで示す）
- **依存**: なし

## 扱う

| 用語・論点 | 何を語るか |
|---|---|
| 著作権法の保護対象 | プログラムも文書も「表現」は自動的に保護される。アイデアそのもの・アルゴリズムは対象外、が試験の急所 |
| 著作権の権利侵害 | 無断コピー・無断改変・無断公開。業務ソフトのコピーやコード流用など職場で起きる例で |
| コピープロテクト外し | 技術的保護手段の回避は、それ自体が違法。「自分で買ったものでもダメ」まで |
| 営業秘密の3要件 | 秘密管理性・有用性・非公知性。3つ全部を満たして初めて不正競争防止法で守られる — 「社外秘と書いて管理する」実務理由につなげる |
| ドメイン名の不正取得 | 他社ブランドに似せたドメインの取得・使用は不正競争行為。フィッシング（L10）の入口対策でもある |

## 扱わない
- ソフトウェア使用許諾契約・コピーレフト（契約で決める側）→ L53
- 特許権・商標権などの産業財産権の詳細 → シラバス用語例にないため深入りしない（保護対象の地図で名前だけ）
- 営業秘密の持ち出し事案の人的対策 → L34（説明済み、参照のみ）

## 確認パート
- 通常クイズ2〜3問
- 出しどころ: 著作権法で保護されないもの（アルゴリズム）の判別／営業秘密の3要件が欠ける事例の判定
