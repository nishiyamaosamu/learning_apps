# SG-L63 Webの仕組みとファイル転送

- **一言で**: ブラウザの裏側 — 1回ごとに忘れるHTTPを、cookieが「あなた」と覚えている
- **シラバス**: 中分類5「ネットワーク応用（Web・ファイル転送）」＋「通信プロトコル（HTTP・FTP）」「ネットワーク接続（プロキシサーバ）」
- **主担当**: なし（L8・L9の【前提：HTTP・cookie】が参照してきた本丸。クッキーの表記はL9に合わせ全編カタカナ）
- **依存**: L61 の後（DNS・ポート番号を既習として使う）

## 扱う

| 用語・論点 | 何を語るか |
|---|---|
| HTTPとHTTPS | ブラウザとサーバの要求・応答のやりとり。暗号化した通り道がHTTPS（仕組みはL42参照） |
| URLとドメイン名 | どのサーバの・どの場所を指すかの読み方。偽ドメインの見分け（L10）に効く実用として |
| cookie | サーバが端末に置くメモ。ログイン状態の維持の裏側で、セッションハイジャック（L9）が狙ったのはこれ、と回収（R5問10の題材） |
| プロキシサーバ | 社内から外への通信をまとめて代理する（R6問10の題材）。URLフィルタリング（L38）やログ取得（L37）の実装場所でもある |
| マークアップ言語とハイパーリンク | HTML（構造を記す）・XML（データを記す）を一言ずつ。リンクで文書がつながるのがWebの本質 |
| FTPとオンラインストレージ | ファイルのアップロード／ダウンロードの古典（FTP）と現代（オンラインストレージ）。共有設定ミスが漏えいの定番、と釘を刺す |

## 扱わない
- XSS・CSRF・セッションハイジャックの手口 → L9（完成済み、参照のみ）
- TLSの仕組み → L42（参照のみ）、リバースプロキシ → L45（説明済み、参照のみ）
- ファイル転送の点検・持出し管理のケース演習 → L87（科目B）
- EC・EDI → L64

## 確認パート
- 通常クイズ2〜3問
- 出しどころ: cookieの役割（R5問10の型）／プロキシサーバの働き（R6問10の型）／HTTPSで守られるもの
