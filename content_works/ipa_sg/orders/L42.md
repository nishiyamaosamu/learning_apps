# SG-L42 セキュアプロトコルの地図

- **一言で**: どの通信を・どの層で守るか — 暗号技術（第2章）が実際の通信で働く場所の地図
- **シラバス**: 情報セキュリティ#5「セキュアプロトコル」全部
- **主担当**: ★ WPA2／WPA3（L65が参照）。TLSの流れの説明は L15・L21 の復習として位置づける
- **依存**: L15・L21 の後（共通鍵／公開鍵・ハイブリッド暗号とデジタル証明書を既習として使う。呼称は narration/ipa_sg/sg-L15-encryption.md に揃える）

## 扱う

| 用語・論点 | 何を語るか |
|---|---|
| 「どの通信をどの層で守るか」の地図 | Web・ネットワーク全体・遠隔操作・無線、それぞれに専用の守り方がある。この地図が回の背骨 |
| TLSとHTTPS（HTTP over TLS） | 証明書でサーバを確認し、公開鍵で共通鍵を渡し、本文は共通鍵で暗号化 — L15のハイブリッド暗号とL21の証明書の復習を1シーンで（R6問6の題材） |
| IPsec | アプリを選ばずIPの層でまるごと暗号化する。VPN（L45）の土台になる、と一言予告 |
| SSH | 遠隔のサーバを安全に操作する。平文のままの遠隔操作が盗聴（L11）にどれだけ弱いかと対で |
| WPA2／WPA3 | 無線LANの暗号化方式（主担当）。古い方式は解読済みで、今はWPA2以上・できればWPA3、まで言い切る |

## 扱わない
- 暗号方式そのもの（AES・RSA・ハイブリッド）→ L15、証明書・認証局 → L21（復習参照のみ）
- VPNの実装（インターネットVPNなど）→ L45、通信サービスとしてのVPN → L64
- 無線LANの規格（IEEE 802.11／Wi-Fi）・SSID・アクセスポイント設定 → L65（この回の定義を参照する側）
- メールを守るプロトコル（S/MIME・SMTP-AUTHなど）→ L43・L44
- HTTPやcookieの仕組み → L63

## 確認パート
- 通常クイズ2〜3問
- 出しどころ: HTTPSで証明書が果たす役割（R6問6の型）／用途とプロトコルの対応（遠隔操作＝SSH、無線＝WPA3）
