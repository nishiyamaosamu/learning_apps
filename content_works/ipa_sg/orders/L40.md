# SG-L40 データ保護の技術

- **一言で**: データは「隠す・確実に消す・出どころを示す・証拠として残す」で守る
- **シラバス**: 情報セキュリティ#4「技術的セキュリティ対策」のうち秘匿化・匿名化・データマスキング・暗号化消去（CE）・電子透かし・デジタルフォレンジックス・AI for Security／Security for AI【地図＋代表】
- **主担当**: なし（匿名加工の手法名（項目削除・一般化・k-匿名化など）の正は **L50**。この回は位置づけの地図だけ）
- **依存**: **L50 の後**（章をまたぐ唯一の後方参照。手法名はL50の呼称＝個人情報保護委員会の呼称に揃える）

## 扱う

| 用語・論点 | 何を語るか |
|---|---|
| データ保護の地図 | 「隠す／消す／出どころを示す／調べる」の4つの目的で技術を並べる。この回は製品（L39）でなくデータ自体に効く技術 |
| 秘匿化・匿名化・データマスキングの位置づけ | 誰に対して何を隠すかの整理。匿名加工の具体的な手法名はL50で定義済みとして参照する |
| 暗号化消去（CE） | 暗号化しておいて鍵を破棄すれば読めなくなる＝消したのと同じ。大容量ディスクを短時間で確実に処分できる理屈 |
| 電子透かし | データに見えない印を埋め込み、出どころや正当な持ち主を示す。漏えい経路の特定にも使える |
| デジタルフォレンジックス | インシデント後に電磁的記録を証拠として保全・調査する技術（R5問3の題材）。電源を切る前にメモリを保全する等「証拠を壊さない」作法が肝 |
| AI for Security／Security for AI | AIで守る（検知の高度化）とAIを守る（プロンプトインジェクション等への防御）の対を1シーンで。詳細は暗記カードへ |

## 扱わない
- 匿名加工の手法名の定義（項目削除/レコード削除/セル削除・一般化・トップ（ボトム）コーディング・丸め・k-匿名化）→ L50（主担当。参照のみ）
- ストレージ暗号化・ファイル暗号化 → L16（説明済み、参照のみ）
- 記憶媒体の物理的な処分 → L41（「論理で消すCE／物理で壊すのは次回」と分担を一言）
- AIを悪用した攻撃・敵対的サンプル → L14（完成済み、参照のみ）
- フォレンジックスを使う初動対応・証拠保全のケース演習 → L94（科目B）、匿名加工のケース演習 → L92（科目B）

## 確認パート
- 通常クイズ2〜3問
- 出しどころ: 暗号化消去の理屈（鍵を捨てる＝読めない）／フォレンジックスで最初にやるべきこと（証拠保全）
