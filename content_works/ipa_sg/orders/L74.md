# SG-L74 企業活動と経営管理

- **一言で**: 会社を回す言葉の地図 — 経営の型（PDCA）・責任者（CxO）・止めない備え（BCP）・変わる力（DX）
- **シラバス**: 中分類11「経営・組織論」（経営管理・ヒューマンリソース・リスクマネジメント・IT利活用の動向）
- **主担当**: なし（L26で予告済みのBCP・BCM・BIAをこの回で本格的に扱う）
- **依存**: L26 の後（情報セキュリティ継続＝IT側の備えを既習として、事業全体の継続に広げる）

## 扱う

| 用語・論点 | 何を語るか |
|---|---|
| PDCA | 計画→実行→評価→改善。ISMS（L28）で見た型が経営一般の型だった、と逆向きに回収 |
| CxOの地図 | CEO・CIO・CDO・CISO・CPO。「何の最高責任者か」の1枚表。CISOがセキュリティの、CPOが個人情報の責任者 |
| リスキリングとeラーニング | 人への投資。学び直しで新しい技術に追いつく。教育（L34）の経営版 |
| BCP・BCM・事業影響度分析（BIA） | 事業を止めない計画（BCP）とそれを回す活動（BCM）。どの業務が止まると痛いかを測るのがBIA。L26・L69の「復旧」がここに束ねられる |
| Society5.0とデータ駆動型社会 | データとAIで社会課題を解く構想。用語として一言ずつ |
| DXの3段階 | デジタイゼーション（紙を電子に）→デジタライゼーション（業務を変える）→DX（事業・組織を変える）。R7問12の題材で、事例の段階判別まで |

## 扱わない
- リーダーシップ・コミュニケーション・ケーススタディの一般論 → 暗記カード
- RTO/RPOなど復旧目標の定義 → L69（説明済み、参照のみ）
- BPR・業務改善の道具 → L72（説明済み、参照のみ）
- データ利活用の流れ・分析手法 → L75・L76

## 確認パート
- 通常クイズ2〜3問
- 出しどころ: CxOの役割判別（CISO・CPOが定番）／DXの3段階の事例判別（R7問12の型）／BIAで測るもの
