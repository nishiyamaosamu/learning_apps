# SG-L6 ★ 攻撃者と不正のメカニズム

- **一言で**: なぜ人は不正をするのか — 3つの条件が揃ったときに起きる、だから条件を1つ崩せば防げる
- **シラバス**: 情報セキュリティ#1「不正のメカニズム」「攻撃者の種類」「攻撃の動機」
- **主担当**: ★ **不正のトライアングル（機会・動機・正当化）**。L34（人的対策）・L95（科目B）はここの言い方を参照する。
  3要素の呼称と「1つ崩せば防げる」という説明の型を、ここで決め切ること
- **依存**: なし（第1章の中では独立。L34・L95 より先に作る）

## 扱う

| 用語・論点 | 何を語るか |
|---|---|
| 不正のトライアングル | 機会・動機・正当化の3つ。**それぞれ具体例を1つずつ**（例: 誰も見ていない／借金／「自分は正当に評価されていない」） |
| 3要素を崩す＝対策 | 組織にできるのは主に「機会」を消すこと。動機・正当化は人の内側にある |
| 状況的犯罪予防 | 環境を変えて「やりにくく・見つかりやすく」する考え方 |
| 割れ窓理論 | 小さな乱れを放置すると大きな不正を呼ぶ。清掃・整頓が対策になる意外性 |
| 防犯環境設計 | 見通し・動線・監視で犯行機会を減らす（物理側の考え方の入口） |
| 攻撃者の種類 | スクリプトキディ／愉快犯／詐欺犯（金銭目的）／内部犯 の地図。**内部犯が最も痛い**理由まで |
| ダークウェブ | 盗まれた情報や攻撃ツールが売買される場。攻撃が「商売」になっている入口 |

## 扱わない
- ハクティビズム・サイバーテロリズム・リークサイト・RaaS → L13（攻撃のビジネス化）
- 内部不正防止ガイドライン・教育・訓練・誓約書などの**対策** → L34
- 科目Bでの内部不正ケース → L95
- ボットハーダー・二重脅迫の仕組み → L5

## 確認パート
- 通常クイズ2〜3問
- 出しどころ: 事例を出して「トライアングルのどれを崩す対策か」を選ばせる／割れ窓理論の意味
