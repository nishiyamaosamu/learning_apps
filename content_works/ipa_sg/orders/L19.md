# SG-L19 多要素認証とパスワードレス

- **一言で**: パスワード1本に頼るのをやめる — 「違う種類の証拠」を重ねる
- **シラバス**: 情報セキュリティ#1「情報セキュリティ技術（利用者認証）」のうち多要素・多段階・SSO・CAPTCHA＋「認証技術」のリスクベース認証
- **主担当**: なし（3要素のうち「生体」の中身は L20 が正）
- **依存**: L18 の後（パスワードの限界を受けて「だから重ねる・なくす」へ進む流れ）

## 扱う

| 用語・論点 | 何を語るか |
|---|---|
| 認証の3要素（記憶・所有・生体） | 知っているもの・持っているもの・本人自身。この地図が回全体の背骨 |
| 多要素認証と多段階認証の違い | 効くのは**種類の違う要素**を重ねること。パスワード2回は多段階だが多要素ではない、が試験の急所 |
| リスクベース認証 | いつもと違う端末・場所のときだけ追加の確認をする。安全性と利便性の折り合い |
| パスワードレス認証（FIDO） | 秘密が端末の外に出ないので、サーバから漏れるものがない。「覚える秘密」自体をなくす発想 |
| シングルサインオン | 1回の認証で複数サービスを利用。便利さの裏で「破られたら全部」も一言添える |
| CAPTCHA | 相手が人間かプログラムかを見分ける。本人確認ではなく機械除け、と位置づけを明確に |

## 扱わない
- 生体認証の方式・FRR/FAR → L20
- パスワード強度・ワンタイムパスワード・セキュリティトークン → L18
- EMV 3-Dセキュア（リスクベース認証の決済応用） → L20
- SaaSの認証設定を選ぶケース演習 → L83（科目B）
