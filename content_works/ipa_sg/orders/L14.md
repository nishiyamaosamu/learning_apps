# SG-L14 AI時代の脅威

- **一言で**: AIは攻撃を**速く・安く・それらしく**する。加えて、AI自身も狙われる対象になった
- **シラバス**: 情報セキュリティ#1「サイバー攻撃手法」（AIを悪用した攻撃）、「脅威」（AIに対する脅威）
- **主担当**: なし。守る側でのAI活用（AI for Security / Security for AI）の正は L40
- **依存**: L3（BEC・ソーシャルエンジニアリング）と L12（標的型）の後。既習の攻撃が「AIでどう変わるか」で語る回

## 扱う

| 用語・論点 | 何を語るか |
|---|---|
| AIで攻撃はどう変わったか | 新種の攻撃が生まれたというより、**既存の攻撃の質と量が上がった**という枠組みを最初に置く |
| フィッシング・BECの巧妙化 | 「日本語が不自然だから偽物」という見分け方が通用しなくなった |
| 亜種マルウェアの生成 | 少しずつ違う亜種を大量に作れる。パターンマッチング（L35）が効きにくくなる |
| 脆弱性発見の効率化 | 攻撃側の下調べが速くなる＝パッチを当てるまでの猶予が縮む |
| ディープフェイク | 音声・映像の偽造。「本人の声で指示された」が根拠にならない（BECと接続） |
| 敵対的サンプル | 人には分からない細工でAIの判断を誤らせる。**AIが狙われる側**の代表例 |
| プロンプトインジェクション | AIへの入力に指示を紛れ込ませ、意図しない出力・情報開示をさせる |

## 扱わない
- 守る側でのAI活用・Security for AI の対策 → L40
- マルウェア検出手法 → L35
- 偽・誤情報とファクトチェック（法務・倫理の観点）→ L54
- 個々の従来型攻撃の仕組み → L3・L12
