# SG-L34 人的セキュリティ対策

- **一言で**: 人は最大の脆弱性で、最初の防衛線 — 教育・訓練・約束で「人の穴」を塞ぐ
- **シラバス**: 情報セキュリティ#4「人的セキュリティ対策」全部
- **主担当**: なし（不正のトライアングルの正は L6＝完成済み。呼称は narration/ipa_sg/sg-L6-fraud-triangle.md の「用語の呼称」表に揃える）
- **依存**: L6 の後（完成済み）。内部不正防止をトライアングルの「機会を奪う」で説明するため

## 扱う

| 用語・論点 | 何を語るか |
|---|---|
| 組織における内部不正防止ガイドライン | 内部不正対策の実務ガイド。L6の不正のトライアングルを対策側から回収し「機会・動機・正当化のどれを潰すか」で整理する |
| 情報セキュリティ啓発・教育 | 全員に基本を浸透させる継続活動。入社時だけでなく繰り返す理由（人は忘れる・手口は変わる） |
| 標的型メール訓練 | 本物そっくりの訓練メールで「開いてしまう人」を責めずに組織の弱点を測る。L3・L12の攻撃側と対 |
| レッドチーム演習 | 攻撃側チームが本気で攻め、防御側の検知・対応力を試す。ペネトレーションテスト（L33）との違いは「人と組織まで試す」こと |
| 認証情報の割当てと管理・セキュリティクリアランス | アカウントを渡す・取り上げる手続と、扱える情報のレベルを人に紐づける考え方 |
| 秘密保持契約・誓約書 | 退職後まで効く「約束」の対策。技術で縛れない部分を契約で縛る |

## 扱わない
- 不正のトライアングル・状況的犯罪予防・割れ窓理論の定義 → L6（完成済み、参照のみ）
- アクセス権の設定・特権管理（技術側の統制）→ L36
- 秘密保持契約の法的な扱い・労働法制 → L53
- 教育・訓練計画の提案と内部不正防止のケース演習 → L95（科目B）
