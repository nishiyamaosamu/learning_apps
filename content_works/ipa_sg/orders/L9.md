# SG-L9 Webを狙う攻撃②：利用者を狙う

- **一言で**: 狙われるのはサーバではなく**そのサイトを使っている人**。信頼されたサイトが加害の道具になる
- **シラバス**: 情報セキュリティ#1「サイバー攻撃手法」（XSS・CSRF・セッション系）
- **主担当**: なし。対策側（エスケープ）の正は L46、cookie の仕組みの正は L63
- **依存**: L8 の後（「サーバを狙う／利用者を狙う」の対比が効く）

## 扱う

| 用語・論点 | 何を語るか |
|---|---|
| 【前提】cookie とセッション | ログイン状態は cookie の「引換券」で保たれている、という1枚だけ。**最大2シーン**。詳しくは L63 |
| クロスサイトスクリプティング（XSS） | 攻撃者の書いたスクリプトが、被害者のブラウザで**そのサイトの一部として**動く |
| セッションハイジャック | 引換券を盗まれるとログインし直さずに成りすませる。XSSの被害の代表として繋げる |
| クロスサイトリクエストフォージェリ（CSRF） | ログイン済みの利用者に、意図しない操作を**本人の権限で**実行させる。XSSとの違いを一言 |
| クリックジャッキング | 透明な層を重ねて、押したつもりのないボタンを押させる |
| ドライブバイダウンロード | サイトを見ただけで感染。改ざんされた正規サイトが起点になる |

## 扱わない
- 入力をだます攻撃（SQLインジェクションほか）→ L8
- 対策（エスケープ・トークン）→ L46
- cookie・HTTP・プロキシの詳しい仕組み → L63
- フィッシング（偽サイトへ誘導する攻撃）→ L10

## 確認パート
- 通常クイズ2〜3問
- 出しどころ: XSS と CSRF の違い（誰のブラウザで何が動くか）／セッションハイジャックの被害
