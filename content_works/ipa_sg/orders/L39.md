# SG-L39 セキュリティ製品・サービスの地図

- **一言で**: 製品名は「どこを守るか」で覚える — 端末・ネットワーク・情報・全体監視の4マス地図
- **シラバス**: 情報セキュリティ#4「技術的セキュリティ対策」〔セキュリティ製品・サービス〕＋携帯端末のセキュリティ【地図＋代表】
- **主担当**: なし
- **依存**: L38 の後（ファイアウォール・IDS/IPSを地図のネットワークのマスに置き直すため）

## 扱う

| 用語・論点 | 何を語るか |
|---|---|
| 守る場所で分類する地図 | 端末／ネットワーク／情報／全体監視の4マス。アルファベット3文字の羅列を場所の絵に変える、が回の背骨 |
| EDR・MDM（端末を守る） | 侵入「後」の端末のふるまいを記録し対応するEDR。会社スマホを一括管理し紛失時に消せるMDM |
| UTM・WAF（ネットワークを守る） | FW・IDS/IPSなどをまとめた詰め合わせがUTM。Webアプリへの攻撃（L8のSQLインジェクション等）専門の盾がWAF |
| DLP（情報を守る） | 守る対象を「データそのもの」にし、機密データの持ち出し・送信を止める |
| SIEM（全体を見る） | 各機器のログを集約・相関分析して攻撃の兆候に気づく。L37のログ管理を製品にしたもの |
| 許可リスト／拒否リストとフォールスネガティブ／フォールスポジティブ | 「良いものだけ通す／悪いものだけ止める」の2方式と、見逃し／誤検知のトレードオフ。検知系すべてに共通する宿命として |

## 扱わない
- SSL/TLSアクセラレーター・Webアイソレーション → 暗記カード（動画では「詳細は暗記カードで」と一言）
- ファイアウォール・IDS/IPSの仕組み → L38（説明済み。地図への配置のみ）
- EDRが対応するマルウェアの手口 → L4・L5（参照のみ）
- マルウェア対策ソフトの検出手法 → L35（説明済み、参照のみ）
- クラウドサービスのセキュリティ → L55、IoTのセキュリティ → L32（説明済み、参照のみ）

## 確認パート
- 通常クイズ2〜3問
- 出しどころ: 事例（ノートPC紛失に備えたい／Webアプリを守りたい）から製品を選ぶ／フォールスポジティブの意味
