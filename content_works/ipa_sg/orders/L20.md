# SG-L20 生体認証と本人確認

- **一言で**: 体そのものを鍵にする — ただし「厳しくするほど本人も弾かれる」
- **シラバス**: 情報セキュリティ#1「情報セキュリティ技術（生体認証技術）」全部＋「利用者認証」のICカード・PINコード・eKYC・EMV 3-Dセキュア
- **主担当**: なし（3要素の枠組みは L19 が正。この回は「生体」要素の深掘り＋残る本人確認の用語）
- **依存**: L19 の後（多要素の地図の中の1マスとして始める）

## 扱う

| 用語・論点 | 何を語るか |
|---|---|
| 身体的特徴による認証 | 静脈・虹彩・顔を代表に。「忘れない・失くさない」が強み |
| 行動的特徴による認証 | 声紋・署名（書き癖）。体の形でなく「動きの癖」も本人の証拠になる |
| 本人拒否率（FRR）と他人受入率（FAR） | 判定を厳しくするとFARが下がりFRRが上がるトレードオフ。**どちらかだけゼロにはできない**が試験の急所 |
| ICカードとPINコード | カード（所有）＋PIN（記憶）で2要素になる。盗難だけでは使えない理由 |
| eKYC | 口座開設などの本人確認をオンラインで完結する仕組み。身分証＋自撮りの例で |
| EMV 3-Dセキュア | カード決済の本人確認。怪しい取引のときだけ追加認証（L19のリスクベース認証の応用と一言） |

## 扱わない
- 認証の3要素・多要素/多段階の枠組み → L19
- 入退室管理でのICカード利用（アンチパスバックなど物理的対策） → L41
- パスワード・ワンタイムパスワード → L18

## 確認パート
- 通常クイズ2〜3問
- 出しどころ: FRRとFARのトレードオフ（判定を厳しくすると何が起きるか）／ICカード＋PINが2要素になる理由
