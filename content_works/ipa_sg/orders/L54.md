# SG-L54 その他の法律・情報倫理・標準化

- **一言で**: 紙をなくす法律・ウソ情報への構え・世界共通のものさし — 法務の章の残りを地図で締める
- **シラバス**: 法務#4「その他の法律・ガイドライン・技術者倫理」全部＋法務#5「標準化関連」【地図＋代表】
- **主担当**: なし
- **依存**: なし（第6章の締め）

## 扱う

| 用語・論点 | 何を語るか |
|---|---|
| 電子化を支える法律の地図 | デジタル社会形成基本法・官民データ活用推進基本法（方向を示す基本法）と、e-文書法・電子帳簿保存法（紙の保存義務を電子でよいとする法）を2階建ての地図で |
| 偽・誤情報の3分類 | ディスインフォメーション（だます意図あり）／ミスインフォメーション（意図なき誤り）／マルインフォメーション（真実を害意で使う）。意図×真偽のマトリクスで |
| ファクトチェック | 拡散する前に出どころを確かめる。組織のSNS運用（L27のガイドライン）にもつながる |
| デジタルタトゥー | 一度出た情報は消せない。投稿前の一呼吸、を倫理として |
| フィルタリング・ペアレンタルコントロール | 有害サイトへのアクセス制限。組織のURLフィルタリング（L38）との違いは「守る対象が子ども」 |
| 標準化の地図 | JIS・ISO・IEEEの役割と、デジュレスタンダード（公的に定めた標準）／デファクトスタンダード（事実上の標準）の対比。JIS Q 27001（L28）はデジュレの例と回収 |

## 扱わない
- コンプライアンスの実務（監査・内部統制）→ L70・L71
- フェイクニュースを作る技術（ディープフェイク）→ L14（完成済み、参照のみ）
- JIS Q 27001・JIS Q 15001の中身 → L28・L50（説明済み、参照のみ）
- 標準化団体の網羅（IETF・W3Cなど）→ 暗記カード

## 確認パート
- 通常クイズ2〜3問
- 出しどころ: 3分類の判別（意図の有無がカギ）／デジュレとデファクトの違い／電子帳簿保存法が認めること
