# SG-L38 ネットワーク防御の仕組み

- **一言で**: 社内と外の「境界」に関所を置く — 通す・止める・気づくの役割分担
- **シラバス**: 情報セキュリティ#4「技術的セキュリティ対策」のうちファイアウォール・DMZ・侵入検知・侵入防止・URLフィルタリング・コンテンツフィルタリング
- **主担当**: なし
- **依存**: なし（【前提：パケットの通り道】を冒頭に置く。詳しい仕組みはL60・L61参照と字幕・まとめで示す）

## 扱う

| 用語・論点 | 何を語るか |
|---|---|
| 【前提】パケットの通り道 | 通信は宛先・送信元・ポート番号を持つ小包（パケット）で流れ、社内と外の境界を必ず通る。前提は最大2シーン（詳細はL60・L61へ） |
| ファイアウォール（パケットフィルタリング） | 境界の関所。宛先・送信元・ポート番号のルールで通す/止めるを機械的に判定する |
| DMZ | 外に公開するサーバを社内LANと分けて置く緩衝地帯。公開サーバが乗っ取られても社内まで入られない配置の工夫 |
| IDS（侵入検知）／IPS（侵入防止） | 関所をすり抜けた怪しい通信に「気づく」IDSと、気づいて「遮断までする」IPS。検知と防止の一字の違いを明確に |
| URLフィルタリング・コンテンツフィルタリング | 中から外への通信も制御する。危険なサイトへのアクセスを止める（行き先で見るか、中身で見るか） |

## 扱わない
- パケットフィルタリングの実装・MACアドレスフィルタリング・認証VLAN・リバースプロキシ → L45（実装技術）
- WAF・UTM・SIEMなど製品の分類 → L39（「FW/IDS/IPSは次回の地図に載る」と予告）
- 検疫ネットワーク → L36（説明済み、参照のみ）
- IPアドレス・ポート番号・ルーティングの詳しい仕組み → L60・L61（第7章）
- 家庭向けのフィルタリング（ペアレンタルコントロール）→ L54

## 確認パート
- 通常クイズ2〜3問
- 出しどころ: IDSとIPSの違い／DMZに置くべきサーバの判別／ファイアウォールが判定に使う情報
