# SG-L71 内部統制

- **一言で**: 不正もミスも「仕組み」で起きにくくする — 1人に任せない・記録が残る業務の作り方
- **シラバス**: 中分類8「内部統制」「法令順守状況の評価・改善」
- **主担当**: なし（不正のトライアングルは L6 が正＝完成済み。「機会を仕組みで奪う」の具体化として参照する）
- **依存**: L70 の後（監査が「見る対象」の中身、という接続）

## 扱う

| 用語・論点 | 何を語るか |
|---|---|
| 内部統制とは | 業務の有効性・報告の信頼性・法令順守を、仕組みとして担保する体制。性善説でなく仕組みで守る |
| 職務分掌 | 申請する人と承認する人を分ける。1人で完結できる業務は不正の機会（L6）そのもの |
| 統制活動とチェック体制 | 実施ルールを決め、承認・照合・実地棚卸などで確かめる（R6問8の題材） |
| 情報と伝達・モニタリング | 決めたことが現場に伝わり、守られているかを常時・定期に見る。内部通報の受け皿もここ |
| ITに係る全般統制／業務処理統制 | システム全体の管理（アクセス権・変更管理・運用）と、個々の業務処理の中のチェック（入力検証など）。L36・L69の既習が全般統制の中身だった、と回収 |
| CSAと内部統制の限界 | 現場が自ら点検する統制自己評価（CSA）と、共謀や経営者自身の不正には効きにくいという限界。だから監査（L70）が要る、で締める |

## 扱わない
- 監査の手順・監査人の独立性 → L70（説明済み、参照のみ）
- 不正のトライアングルの定義 → L6（完成済み、参照のみ）
- 職務分掌をアクセス権に落とす実装 → L36（説明済み、参照のみ）
- 内部不正防止ガイドライン → L34（説明済み、参照のみ）

## 確認パート
- 通常クイズ2〜3問
- 出しどころ: 職務分掌に反する事例の判別（R6問8の型）／全般統制と業務処理統制の判別／内部統制の限界の例
