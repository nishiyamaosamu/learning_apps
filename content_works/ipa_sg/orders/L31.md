# SG-L31 セキュリティ機関の地図

- **一言で**: 自社の外にも味方がいる — 国の司令塔・実働部隊・支援制度の3層地図
- **シラバス**: 情報セキュリティ#2「情報セキュリティ組織・機関」の外部機関側【地図＋代表】（組織内側の委員会・CSIRT等はL30が担当済み）
- **主担当**: なし
- **依存**: L30 の後（「自社のCSIRTだけでは足りないとき、外の誰を頼るか」と接続して始める）

## 扱う

| 用語・論点 | 何を語るか |
|---|---|
| 3層の地図 | 司令塔（方針を決める）／実働（動く・助ける）／制度（届け出る・認定する）。この地図が回の背骨で、以降は各層の代表 |
| サイバーセキュリティ戦略本部とNISC | 国の司令塔と、その事務局。サイバーセキュリティ基本法（L48）に基づく、と一言だけ予告 |
| IPAセキュリティセンターとJPCERT/CC | 実働の代表2つ。注意喚起・届出受付のIPA、インシデント対応の調整役のJPCERT/CC |
| J-CSIP・J-CRAT・JVN | 情報共有（J-CSIP）・標的型攻撃のレスキュー（J-CRAT）・脆弱性情報のデータベース（JVN）を一言ずつ |
| 届出制度と早期警戒パートナーシップ | 不正アクセス・脆弱性を見つけたら届け出る窓口と、発見者→IPA→開発者へ橋渡しする枠組み |
| ISMAP・SECURITY ACTION・NOTICE | 制度の代表3つ。政府調達クラウドの評価（ISMAP）、中小企業の自己宣言（SECURITY ACTION）、IoT機器の調査（NOTICE） |

## 扱わない
- ISAC・Trusted Web推進協議会・情報セキュリティサービス基準／審査登録制度／適合サービスリスト・再発防止のための提言・啓発活動 → 暗記カード（動画では「詳細は暗記カードで」と一言）
- CRYPTREC → L16（暗号リストの機関として説明済み。参照のみ）
- サイバーセキュリティ基本法の中身 → L48
- 組織内の体制（委員会・CSIRT・PSIRT・SOC）→ L30

## 確認パート
- 通常クイズ2〜3問
- 出しどころ: 機関名と役割の対応（JPCERT/CC・J-CRATあたりが定番）／脆弱性を発見したときの届出先
