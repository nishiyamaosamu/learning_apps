# SG-L75 業務分析の手法

- **一言で**: 問題は「見える形」にして初めて解ける — 図で原因を探すQC七つ道具と発想の道具
- **シラバス**: 中分類11「業務分析・データ利活用（OR・IE）」【地図＋代表】
- **主担当**: なし
- **依存**: なし

## 扱う

| 用語・論点 | 何を語るか |
|---|---|
| QC七つ道具の地図 | 数値データを図にして問題を見つける道具箱。代表4つをこの後で見る、と地図から（網羅は暗記カード） |
| 特性要因図 | 結果（特性）に効く原因を骨のように整理する魚の骨の図。インシデントの原因分析（L68の問題管理）にも使える |
| パレート図 | 件数の多い順に並べて累積で見る。「上位2割の原因が8割を占める」を見つける図（R5問12・R6問12の題材） |
| 管理図とヒストグラム | ばらつきが正常範囲かを時系列で見る管理図と、分布の形で見るヒストグラム。「いつもと違う」に気づく道具として対で |
| 新QC七つ道具とブレーンストーミング・デルファイ法 | 言葉のデータを整理する新QC（1シーンの地図）と、アイデア出し（批判禁止のブレスト）・専門家の意見を収束させるデルファイ法 |
| サンプリングとシミュレーション | 全部調べられないから一部で推し量る・実物で試せないから模擬で試す。分析の前提となる2つの考え方 |

## 扱わない
- QC七つ道具の残り（散布図・チェックシート・層別）・新QC七つ道具の個々の図 → 暗記カードへ委譲（**これは範囲切り分けの内部記録**。暗記カードなど他機能への誘導はナレーション・画面に書かない。単に語らない）
- デシジョンツリー・期待値 → L76（次回の計算ワーク）
- 統計的バイアス・データ分析の流れ → L76

- 通常クイズ2〜3問
- 出しどころ: 図の名前と用途の対応（パレート図が定番。R5問12・R6問12の型）／デルファイ法の手順の特徴
