# SG-L45 ネットワークセキュリティの実装

- **一言で**: 境界防御（L38）を実装に落とす — 通す相手を絞り、通り道を暗号化し、罠も仕掛ける
- **シラバス**: 情報セキュリティ#5「ネットワークセキュリティ」全部
- **主担当**: なし
- **依存**: L38 の後（ファイアウォール・DMZの概念は説明済み。この回は「実際に何を設定するか」の粒度）

## 扱う

| 用語・論点 | 何を語るか |
|---|---|
| パケットフィルタリングの実装 | L38の関所を設定の目線で再訪。「どのIP・どのポートを許可するか」のルール表を1枚見せる |
| MACアドレスフィルタリング | 機器固有の番号で接続を制限する。ただし偽装できるので過信しない、まで添える |
| 認証サーバ・認証VLAN | つないだ人を認証してから、所属に応じたネットワークに割り当てる。「つなげた＝入れた」にしない仕組み |
| VPN | 公衆網の上に暗号化された専用トンネルを作る（IPsecはL42参照）。テレワークの定番、と実感で |
| ハニーポット | わざと弱そうな囮を置き、攻撃者の手口を観察する。守り一辺倒でない対策として |
| リバースプロキシ | 外からのアクセスをサーバの手前で受けて中継する。サーバを直接さらさない配置の工夫 |

## 扱わない
- ファイアウォール・DMZ・IDS/IPSの概念 → L38(説明済み、参照のみ）
- IPsec・TLSの仕組み → L42（参照のみ）
- 通信サービスとしてのVPNの種類（IP-VPN・インターネットVPN・広域Ethernet）→ L64
- RADIUS（認証サーバのプロトコル名）→ L61で名前を出す。この回では「認証サーバ」の働きまで
- プロキシサーバの基本（順方向）→ L63

## 確認パート
- 通常クイズ2〜3問
- 出しどころ: 認証VLANの狙い／ハニーポットの目的（防御でなく観察）／リバースプロキシの置き場所
