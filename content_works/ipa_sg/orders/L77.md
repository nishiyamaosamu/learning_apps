# SG-L77 会計・財務の基礎

- **一言で**: いくらで作り、いくらで売れば儲かるか — 損益分岐点と、会社の健康診断書の読み方
- **シラバス**: 中分類11「会計・財務（企業活動と会計・財務諸表）」
- **主担当**: なし（第8章＝科目A範囲の最終回）
- **依存**: なし（既存デモ動画 `bep-fixed-variable-cost` の構成・イラストを流用できる。QUEUE.md のメモ参照）

## 扱う

| 用語・論点 | 何を語るか |
|---|---|
| 固定費と変動費・原価 | 売れなくてもかかる費用と、売るほど増える費用。この分解が損益分岐点の準備 |
| 粗利益と営業利益 | 売上から原価を引いた粗利益、さらに販管費を引いた営業利益。引き算の階段の図で |
| 【計算ワーク】損益分岐点 | 損も得もしない売上高を1問実演。固定費÷（1−変動費率）の型（反復ドリルは問題集） |
| 減価償却費 | 高い設備は買った年に全額費用にせず、使う年数で分けて計上する。サーバ購入とクラウド利用（経費）の違いにも一言 |
| リースとレンタル | 借りて使う2つの形。期間と中途解約の可否の対比だけ |
| 貸借対照表とキャッシュフロー計算書・流動比率 | ある時点の財産と借金の一覧（B/S）と、お金の出入り（C/F）。すぐ返せる力を見る流動比率まで（資産・負債の細かい分類は暗記カード） |

## 扱わない
- 資産・負債の詳細分類（繰延資産・有形/無形など）→ 暗記カード
- 損益計算書の全項目・経常利益以降 → 暗記カード（粗利益・営業利益まで）
- 投資対効果の評価 → L72（説明済み、参照のみ）
- IT資産のライセンス管理 → L68（説明済み、参照のみ）

## 確認パート
- 通常クイズ2〜3問（計算ワークとは別枠）
- 出しどころ: 固定費と変動費の判別／減価償却の考え方／流動比率が示すもの
