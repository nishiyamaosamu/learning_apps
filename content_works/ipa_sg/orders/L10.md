# SG-L10 通信を狙う攻撃①：なりすましと誘導

- **一言で**: 送信元も検索結果も偽装できる — 「誰から来たか」を信じさせて、偽物のほうへ連れていく攻撃
- **シラバス**: 情報セキュリティ#1「サイバー攻撃手法」（フィッシング・スプーフィング系）
- **主担当**: なし。送信元ドメイン認証（SPF/DKIM/DMARC）による対策の正は L43
- **依存**: なし。L11 とは「誘導する／割り込む」で分担

## 扱う

| 用語・論点 | 何を語るか |
|---|---|
| 【前提】送信者は偽装できる | メールの差出人欄は自己申告にすぎない、という1枚だけ。**最大2シーン**。配送の仕組みは L62 |
| フィッシング | 本物そっくりの通知で偽サイトへ誘導し、入力させる。**この回の主役** |
| スミッシングほか | SMS・SNS・電話など経路違いの派生。手口の本質は同じ、と一言でまとめる |
| SEOポイズニング | 検索結果の上位に悪意あるサイトを出す。「検索して出てきた＝安全」ではない |
| IPスプーフィング | 送信元IPアドレスを偽る。誰から来たかで判断する仕組みが破られる |
| 第三者中継（オープンリレー） | 設定不備のメールサーバが、他人の迷惑メール送信に使われる（自分が加害者側になる） |

## 扱わない
- 通信への割り込み（MITM・MITB・DNSキャッシュポイズニング・リプレイ攻撃）→ L11
- SPF・DKIM・DMARC による対策 → L43
- OP25B・ベイジアンフィルタリングなどスパム対策 → L44
- メール配送・DNS の詳しい仕組み → L62・L61
- 標的型攻撃メール → L12

## 確認パート
- 通常クイズ2〜3問
- 出しどころ: 差出人欄が本物に見えても信用できない理由／オープンリレーで自社が受ける不利益
