# SG-L24 リスクアセスメント

- **一言で**: 洗い出し、測り、順位を付ける — 特定→分析→評価の3ステップとリスク値の計算
- **シラバス**: 情報セキュリティ#2「リスク分析と評価（情報セキュリティリスクアセスメント）」全部
- **主担当**: ★ リスクアセスメントのプロセス（特定→分析→評価、リスク値）。L80・L90（科目B）が参照する
- **依存**: L23 の後（情報資産の重要度がリスク値の入力になる）

## 扱う

| 用語・論点 | 何を語るか |
|---|---|
| リスク基準（リスク受容基準） | 測る前に「どこから上を問題とするか」の物差しを決める。後出しで基準を動かさないため |
| リスク特定→リスク分析→リスク評価 | 3ステップの流れが回の背骨。洗い出す→大きさを測る→基準と比べて順位を付ける |
| リスクレベルとリスクマトリックス | 発生のしやすさ×影響の大きさの表で見える化する。マス目のどこにあるかで扱いが決まる |
| リスク所有者 | リスクごとに責任者を決める。「みんなのリスク」は誰も対応しない |
| 定性的分析／定量的分析 | 言葉の格付けで測るか、金額・数値で測るか。L23の得点法・年間予想損失額を回収 |
| 【計算ワーク】リスク値＝重要度×脅威×脆弱性 | R5問13の型を1問実演。表から3つの値を拾って掛けるだけ、を体験させる（反復ドリルは問題集） |
| リスク忌避・リスク選好 | 組織がリスクをどれだけ取りに行くかの姿勢。基準の背景として一言 |

## 扱わない
- リスク対応（回避・共有・保有・低減）と残留リスク → L25
- リスク源（用語のみ）→ 特定のシーン内で一言、深掘りは暗記カード
- リスク値算定のケース演習（しきい値で対応要否を判定）→ L80（科目B）
- クラウドサービスの可用性評価への応用 → L90（科目B）

## 確認パート
- 通常クイズ2〜3問（計算ワークとは別枠）
- 出しどころ: 3ステップの並び順／リスク基準を先に決める理由／マトリックスの読み取り
