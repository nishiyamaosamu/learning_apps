# SG-L65 無線LAN

- **一言で**: 電波は壁を越える — 便利さと引き換えの無線LANを正しく設定して守る
- **シラバス**: 中分類5「ネットワークの種類と特徴（無線LAN・SSID）」「通信プロトコル（IEEE 802.11a/b/g/n/ac/ax・Wi-Fi 4/5/6/6E）」＋無線LANアクセスポイントの設定
- **主担当**: なし（WPA2／WPA3の正は L42。narration の呼称に揃える）
- **依存**: L42 の後（WPA2/WPA3は定義済みとして「設定で選ぶもの」として扱う）

## 扱う

| 用語・論点 | 何を語るか |
|---|---|
| 無線LANの性質 | 配線いらずの便利さと、電波が敷地の外まで届く危うさ。盗聴（L11）が物理的に容易になる、が回の前提 |
| SSID | ネットワークの名前。ステルス化（名前を隠す）はできるが、それだけでは守れない |
| IEEE 802.11とWi-Fiの世代 | 802.11a/b/g/n/ac/axという規格名と、Wi-Fi 4/5/6/6Eという呼び名の対応。「新しいほど速い」だけ押さえる |
| アクセスポイントの設定 | 暗号化方式の選択（WPA2以上、できればWPA3＝L42参照）・管理パスワードの変更・ゲスト用の分離。「買ったまま使わない」を合言葉に |
| MACアドレスフィルタリングの位置づけ | 補助にはなるが偽装可能（L45で説明済み）。暗号化の代わりにはならない |
| 公衆Wi-Fiの注意 | 偽アクセスポイント（悪魔の双子）につなぐと中間者攻撃（L11）の舞台に。社外ではVPN（L45）併用まで |

## 扱わない
- WPA2／WPA3の方式そのもの → L42（説明済み、参照のみ）
- 中間者攻撃・盗聴の手口 → L11（完成済み、参照のみ）
- LTE・5G・テザリング → L64（説明済み、参照のみ）
- RADIUS認証・認証VLANとの連携 → L45・L61（説明済み、参照のみ）
