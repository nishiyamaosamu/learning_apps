# SG-L7 パスワードを狙う攻撃

- **一言で**: パスワードの破り方は4通り — どれを狙われているかで、効く守り方が変わる
- **シラバス**: 情報セキュリティ#1「サイバー攻撃手法」（パスワード関連）
- **主担当**: なし。対策側（強度・使い回し対策）の正は L18
- **依存**: なし。**L18 と対になる回**なので、攻撃側だけを担当し対策には踏み込まない

## 扱う

| 用語・論点 | 何を語るか |
|---|---|
| 辞書攻撃 | よく使われる語を試す。「複雑さ」より「ありがち」が危ない |
| 総当たり（ブルートフォース）攻撃 | 全パターンを試す。桁数が増えると急に破れなくなることを数で見せる |
| リバースブルートフォース攻撃 | パスワードを固定してIDを変える。**ロックアウトをすり抜ける**のが要点 |
| パスワードリスト攻撃 | 他所で漏れたID/パスワードの組をそのまま試す。使い回しが致命傷になる |
| 4つの違いの整理 | 「何を固定して何を変えるか」の対比で一枚にまとめる |

## 扱わない
- パスワード強度・使い回し対策・ワンタイムパスワード・チャレンジレスポンス認証 → L18
- 多要素認証・パスワードレス（FIDO）→ L19
- キーロガーによる窃取 → L4
- パスワードリマインダの注意点 → L18

## 確認パート
- 通常クイズ2〜3問
- 出しどころ: リバースブルートフォースがアカウントロックで防げない理由／リスト攻撃に効く唯一の対策は「使い回さない」
