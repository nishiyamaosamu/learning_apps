# SG-L61 ネットワークの基礎②：つなぐ機器と名前解決

- **一言で**: パケットは機器がバケツリレーで運ぶ — 誰が運び、名前はどう住所になるか
- **シラバス**: 中分類5「ネットワーク接続（機器）」「インターネット技術（ルーティング・DNS・RADIUS）」「通信プロトコル（DHCP・ポート番号）」「ネットワーク管理（障害管理）」
- **主担当**: なし（L11のDNSキャッシュポイズニング・L38の前提シーンが参照してきた本丸）
- **依存**: L60 の後（IPアドレスとネットワークの区切りを既習として使う）

## 扱う

| 用語・論点 | 何を語るか |
|---|---|
| つなぐ機器の地図 | スイッチングハブ・ブリッジ（LANの中）、ルータ・L3スイッチ（ネットワークの間）、ゲートウェイ（別世界への出入口）。「どの階層でつなぐか」の1枚地図で |
| ルーティング | ルータが宛先ネットワークへの道を選ぶ。バケツリレーの各中継点が次の行き先を決める絵で |
| DNS | 名前（ドメイン名）を住所（IPアドレス）に変える電話帳。L11のDNSキャッシュポイズニングが「この電話帳を汚す攻撃だった」と回収 |
| DHCP | つないだ端末に住所を自動で貸し出す。「設定なしでつながる」の裏側 |
| ポート番号 | 同じ住所の中の窓口番号。Webは443、メールは25など、ファイアウォール（L38）のルールがこれだったと回収 |
| RADIUSと認証サーバ | 認証を1か所で引き受ける仕組みの名前。L45の認証サーバ・認証VLANの実体と接続 |
| 障害の切分けと復旧措置 | どこまで届くかを順に確かめて原因を絞る。稼働統計を平時から取っておくと異常に気づける、まで |

## 扱わない
- IPアドレス・サブネット → L60（説明済み、参照のみ）
- プロキシサーバ → L63、無線LANアクセスポイント → L65
- DNSキャッシュポイズニングの手口 → L11（完成済み、参照のみ）
- メール・Webのアプリケーション層プロトコル → L62・L63

## 確認パート
- 通常クイズ2〜3問
- 出しどころ: DNSの役割／DHCPが配るもの／機器と役割の対応（ルータ＝ネットワーク間）
