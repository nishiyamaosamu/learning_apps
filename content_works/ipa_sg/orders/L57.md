# SG-L57 冗長化と信頼性設計

- **一言で**: 壊れても止まらないシステムは「二重に持つ」と「壊れ方を設計する」で作る
- **シラバス**: 中分類3「システム構成」のうち冗長構成・ストレージの構成・信頼性設計
- **主担当**: なし（稼働率・RASISの定義は L56 が正。この回は稼働率を「上げる手段」の側）
- **依存**: L56 の後（「可用性を上げるには」と指標側から接続する）

## 扱う

| 用語・論点 | 何を語るか |
|---|---|
| 冗長構成と負荷分散 | 同じものを複数持てば1つ壊れても続けられる。普段から仕事を分け合うのが負荷分散 |
| デュアルシステムとデュプレックスシステム | 2系統で同じ処理をして照合するか、主系（現用系）が倒れたら従系（待機系）に切り替えるか。費用と切替時間の対比で |
| クラスタ | 複数台を1つのシステムとして束ねる。仮想化（L55）とあわせて現代の標準構成と一言 |
| RAIDとNAS・SAN | ディスクを束ねて速度や耐障害性を上げるRAID、ネットワーク越しの共有ストレージ（NAS）と専用網（SAN）。置き場所の絵で |
| フォールトトレラント | 部品が壊れても全体は動き続ける設計思想。ここまでの構成の総称として |
| フェールセーフとフールプルーフ | 壊れたら安全側に倒す／人が間違えても事故にならない。ヒューマンエラー前提の設計として対で覚える |

## 扱わない
- 稼働率・MTBF/MTTRの計算 → L56（説明済み、参照のみ）
- コールドスタンバイ／ホットスタンバイ（サービス継続の文脈）→ L69（デュプレックスとの関係は一言で予告）
- バックアップ方式 → L59
- UPS・電源設備 → L41（説明済み、参照のみ）

- 出しどころ: デュアルとデュプレックスの違い／フェールセーフとフールプルーフの事例判別（定番）
