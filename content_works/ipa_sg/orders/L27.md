# SG-L27 情報セキュリティ諸規程

- **一言で**: ルールは3階層で書く — 方針は変えず、手順は現場で変えられるようにする
- **シラバス**: 情報セキュリティ#2「情報セキュリティ諸規程（情報セキュリティポリシーを含む組織内規程）」【地図＋代表】
- **主担当**: なし（ポリシーの位置づけは L22 が入口として触れており、この回が階層構造の正）
- **依存**: L22 の後（四つの柱の「ポリシー」の柱を深掘る回、と位置づけて始める。呼称はL22に揃える）

## 扱う

| 用語・論点 | 何を語るか |
|---|---|
| 方針・対策基準・実施手順の3階層 | 上ほど抽象的で変わらず、下ほど具体的で頻繁に変わる。この構造が回の背骨 |
| 情報セキュリティ方針 | 経営層が組織の内外に宣言する最上位文書。目的（何のために守るか）もここで示す |
| 組織内規程の地図＋代表 | 情報管理規程・インシデント対応規程・例外の規程・規程の承認手続を代表に「対策基準の中身は規程の束」と見せる（網羅は暗記カード） |
| プライバシーポリシー（個人情報保護方針） | 個人情報の扱いを外部に約束する文書。セキュリティポリシーとの違いは「誰に向けた宣言か」 |
| ソーシャルメディアガイドライン | SNS利用のルール。L3（SNSの悪用）を対策側から回収する |

## 扱わない
- 秘密情報管理規程・文書管理規程・教育の規程・職務規程・罰則の規程・対外説明の規程・規則更新の規程 → 暗記カード（地図の中で「こうした規程が並ぶ」と見せるのみ）
- ISMSの文書化要求との関係 → L28
- 個人情報保護法の中身 → L49
- 規程の見直し・改訂のケース演習 → L96（科目B）

- 通常クイズ2〜3問
