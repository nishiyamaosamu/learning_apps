# SG-L56 システムの評価指標と稼働率

- **一言で**: システムの良さは数字で語る — 速さ・信頼性・お金の3つの物差し
- **シラバス**: 中分類3「システムの評価指標」全部＋物理的セキュリティ対策の「RASIS」
- **主担当**: ★ 稼働率・MTBF/MTTR・RASIS（L41＝説明済みの参照元・L57が参照）
- **依存**: なし

## 扱う

| 用語・論点 | 何を語るか |
|---|---|
| レスポンスタイムとスループット | 1件の応答の速さと、単位時間にこなせる量。「窓口の速さ」と「行列のさばき」の対比で |
| RASIS（主担当） | 信頼性・可用性・保守性・保全性・安全性の5観点。「壊れにくく・止まらず・直しやすく・データ正しく・漏れない」と日本語で先に言う |
| MTBFとMTTR | 故障までの平均時間（長いほど良い）と修理の平均時間（短いほど良い）。次の稼働率の材料 |
| 【計算ワーク】稼働率 | 稼働率＝MTBF÷（MTBF＋MTTR）。R6問9の型を1問実演（反復ドリルは問題集） |
| 初期コストと運用コスト | イニシャル／ランニング。安く買っても運用が高くつく話で、評価は総額で、と締める |

## 扱わない
- 直列・並列システムの稼働率の合成計算 → 問題集タブに委譲（動画は単体の1問まで）
- 冗長構成・フォールトトレラントなど信頼性を「設計で上げる」側 → L57（この回は「測る」側と分担）
- UPS・耐震耐火などの設備 → L41（説明済み、参照のみ）
- SLAの可用性目標としての利用 → L67（参照予告のみ）

- 通常クイズ2〜3問（計算ワークとは別枠）
- 出しどころ: MTBFとMTTRどちらを長く/短くしたいか／RASISの観点と事例の対応
