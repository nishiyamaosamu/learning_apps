# SG-L50 個人情報保護法②：加工情報と関連制度

- **一言で**: 個人情報は「加工すれば活用できる」— その加工の作法と、周辺の制度の地図
- **シラバス**: 法務#2「個人情報保護法」の後半（匿名加工情報・仮名加工情報・マイナンバー法・JIS Q 15001・OECD・GDPR・PIA）＋情報セキュリティ#4の「匿名化の手法」
- **主担当**: ★ 匿名加工の手法名（項目削除/レコード削除/セル削除・一般化・トップ（ボトム）コーディング・丸め・k-匿名化）。呼称は個人情報保護委員会の資料に統一する。L40・L92 が参照する
- **依存**: L49 の後（個人情報の定義・事業者の義務を既習として使う）。**この回が終わるまで L40（第4章）は着手できない**

## 扱う

| 用語・論点 | 何を語るか |
|---|---|
| 匿名加工情報 | 個人を再識別できないよう加工すれば、本人同意なしで第三者提供できる。活用と保護の両立、が制度の狙い |
| 仮名加工情報 | 他の情報と照合しなければ特定できない状態。社内の分析用で、第三者提供は原則不可 — 匿名加工との違いを表で |
| 匿名加工の手法名（主担当） | 項目削除／レコード削除／セル削除、一般化、トップ（ボトム）コーディング、丸め、k-匿名化。それぞれ「表のどこをどう消す・ぼかすか」を1枚の表の変形で見せる |
| マイナンバー法・特定個人情報 | マイナンバーを含む個人情報は特定個人情報として通常より厳格（利用目的の限定・提供制限） |
| JIS Q 15001とプライバシーマーク | 個人情報保護の仕組みの規格と、その認証マーク。ISMS認証（L29）の個人情報版という対比で |
| 国際的な枠組みの地図（1シーン） | OECDプライバシーガイドライン・GDPR・PIAを一言ずつ。詳細は暗記カードへ |

## 扱わない
- 個人情報の定義・要配慮個人情報・第三者提供の原則 → L49（説明済み、参照のみ）
- 秘匿化・データマスキングなど技術側の位置づけ → L40（この回の手法名を参照する側）
- プライバシーフレームワーク → 暗記カード
- 項目ごとに手法を選ぶケース演習 → L92（科目B、R7問15型）

## 確認パート
- 通常クイズ2〜3問
- 出しどころ: 匿名加工と仮名加工の違い（第三者提供の可否）／手法名と操作の対応（k-匿名化・トップコーディングが定番）
