# SG-L60 ネットワークの基礎①：IPアドレス

- **一言で**: ネットワークは「住所」で動く — IPアドレスの読み方と、ネットワークの区切り方
- **シラバス**: 中分類5「ネットワークの種類と特徴（LAN・WAN）」「インターネット技術（TCP/IP・IPアドレス）」「通信プロトコル（ネットワーク層・LANとWANのEthernet）」
- **主担当**: なし（L38の【前提：パケットの通り道】が参照してきた本丸）
- **依存**: なし

## 扱う

| 用語・論点 | 何を語るか |
|---|---|
| LANとWAN | 建物の中の網と、その間をつなぐ網。インターネットはWANの親玉、という地図から |
| TCP/IPとEthernet | 世界共通の通信ルールの束（TCP/IP）と、LANの中の配線・伝送の規格（Ethernet）。層が違う、をポストと道路の例えで |
| IPv4とIPv6 | 32ビットの住所は枯渇したので128ビットへ。表記の見た目の違いが分かれば十分 |
| グローバル／プライベートIPアドレス | 世界で一意の住所と、社内だけで通じる住所。家庭のルータの内側は全部プライベート、と実感で |
| サブネットマスクとネットワークアドレス | 住所のどこまでが「町名」（ネットワーク部）かを示すのがマスク。同じ町なら直接届く |
| 【計算ワーク】ネットワークアドレスを求める | R8問10の型を1問実演。IPアドレスとサブネットマスクから同じネットワークかを判定する（反復ドリルは問題集） |

## 扱わない
- ルータ・スイッチなどの機器・ルーティング・DNS・DHCP・ポート番号 → L61
- 無線LAN（SSID・IEEE 802.11）→ L65
- IPスプーフィング（攻撃側）→ L10（完成済み、参照のみ）
- ISP・通信サービスの種類 → L64
- 通信ネットワークの役割（ネットワーク社会・情報社会・ICT）→ 暗記カード（導入の背景として一言流す程度で、用語としては定義しない）

## 確認パート
- 通常クイズ2〜3問（計算ワークとは別枠）
- 出しどころ: グローバルとプライベートの判別／IPv6にした理由／マスクの役割
