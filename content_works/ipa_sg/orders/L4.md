# SG-L4 マルウェアの種類

- **一言で**: マルウェアは「どうやって入り、どう増えるか」で分類すると迷わない
- **シラバス**: 情報セキュリティ#1「脅威」〔マルウェア・不正プログラム〕の前半（感染・侵入のしかたで分かれる基本5種）【地図＋代表】
- **主担当**: なし（マルウェアの分類地図の正はこの回。L5がこの地図の続き＝「入ったあと何をするか」を担当済み）
- **依存**: L3 の後（人為的脅威の地図から「プログラムによる脅威」へ引き継ぐ）

## 扱う

| 用語・論点 | 何を語るか |
|---|---|
| マルウェアという総称と分類の軸 | 悪意あるソフトの総称。名前の暗記でなく「感染のしかた」で分ける、が回の背骨 |
| コンピュータウイルス・マクロウイルス | 他のファイルに寄生して、開かれると発症する。文書ファイルのマクロに潜むのがマクロウイルス |
| ワーム | 宿主が要らず、ネットワーク越しに自力で増殖する。ウイルスとの違いは「寄生するか自走するか」の一点 |
| トロイの木馬 | 便利なソフトのふりをして自分でインストールさせる。増殖しない代わりに気づかれない、が怖さ |
| スパイウェア・キーロガー | 潜んで情報を盗み続ける系統。キー入力を記録するキーロガーはパスワード窃取（L7）の道具になる、と予告 |
| 分類地図のまとめ | 寄生する／自走する／化けて入る／潜んで盗む、の1枚地図で締め。細かい亜種は網羅せず代表だけに絞る（※これは範囲切り分けの内部記録。「暗記カードで補える」等の他機能への誘導はナレーション・画面に書かない） |

## 扱わない
- ランサムウェア・ボット（ボットネット・C&C・RAT）・バックドア・ルートキット・ファイルレスマルウェア → L5（「入ったあと何をするか」の回）
- マルウェアの検出手法・対策ソフト → L35
- AIによる亜種マルウェア生成 → L14
- ウイルス作成罪 → L51

## 確認パート
- 通常クイズ2〜3問
- 出しどころ: ウイルスとワームの違い（寄生の有無が定番）／トロイの木馬の侵入経路の特徴
