# SG-L76 データ利活用と意思決定

- **一言で**: データは集めて・整えて・分析して・使う — そして数字にもだまされ方がある
- **シラバス**: 中分類11「業務分析・データ利活用（データ利活用）」＋デシジョンツリー
- **主担当**: なし（DWH・データレイクなど置き場所の地図は L58 が済み。この回は「使う流れ」の側）
- **依存**: L75 の後（分析の道具を既習として、流れ全体に広げる）

## 扱う

| 用語・論点 | 何を語るか |
|---|---|
| データ利活用の流れ | 収集→加工（整備）→分析→活用の4ステップ（R8問11の題材）。この流れが回の背骨 |
| データの収集（Webクローリング・スクレイピング） | Web上のデータを機械的に集める。利用規約・著作権（L47）への配慮も一言 |
| 【計算ワーク】デシジョンツリーと期待値 | 選択肢×確率で期待値を計算して意思決定する。R8問12の型を1問実演（反復ドリルは問題集） |
| ビッグデータとデータサイエンス | 量・種類・速度が桁違いのデータを分析に使う。置き場所（DWH・データレイク）はL58の地図を参照 |
| 精度と偏り | データが多くても偏っていれば結論は歪む。「たくさん＝正しい」ではない |
| 統計的バイアスと認知バイアス | データの集め方の歪みと、人の思い込みの歪み。数字を疑う目で締める |

## 扱わない
- DWH・データマート・データレイクの定義 → L58（説明済み、参照のみ）
- QC七つ道具・サンプリング → L75（説明済み、参照のみ）
- AI・生成AIの活用促進 → L72（説明済み、参照のみ）
- データの可視化の図法 → L75と暗記カードに委譲

## 確認パート
- 通常クイズ2〜3問（計算ワークとは別枠）
- 出しどころ: 利活用の流れの順序（R8問11の型）／バイアスの事例判別（統計的か認知か）
