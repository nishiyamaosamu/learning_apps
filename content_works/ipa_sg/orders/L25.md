# SG-L25 リスク対応

- **一言で**: 測ったリスクにどう手を打つか — やめる・移す・受け入れる・減らすの4択
- **シラバス**: 情報セキュリティ#2「リスク分析と評価（情報セキュリティリスク対応）」全部
- **主担当**: ★ リスク対応の4分類（回避・共有（移転/分散）・保有・低減）。L66・L73・L81 が参照する
- **依存**: L24 の後（評価で順位が付いたリスクが入力。特定→分析→評価→対応で章のリスク3部作が完結）

## 扱う

| 用語・論点 | 何を語るか |
|---|---|
| リスク回避 | リスクの原因ごとやめる（そのサービスを提供しない等）。得られたはずの利益も捨てる判断 |
| リスク共有（移転・分散） | 他者と分け合う。保険や外部委託が移転、拠点を分けるのが分散 |
| リスク保有 | 対策せず受け入れる。「小さいリスクまで潰すとコスト倒れ」という積極的な判断であることを強調 |
| リスク低減 | 対策で発生可能性や影響を下げる。実務で最も多い選択肢で、第4章の対策群への橋渡し |
| リスクコントロール／リスクファイナンシングの分類地図 | 4分類を「損失そのものを抑える／お金で備える」の軸で整理し直す。サイバー保険・リスクヘッジをここに置く |
| 残留リスク | どれを選んでもリスクはゼロにならない。残ったリスクは保有として引き受け、見直しを続ける |
| 関連用語の地図（1シーン） | リスク集約・リスク対応計画・リスク登録簿・リスクコミュニケーションを一言ずつ。詳細は暗記カードへ |

## 扱わない
- リスクアセスメント（特定→分析→評価）→ L24（参照のみ）
- 管理策の4区分（組織的・人的・物理的・技術的）→ L29
- 対応策選定のケース演習 → L81（科目B）
- プロジェクトのリスク対応（L66）・システム化計画のリスク分析（L73）→ 各回がこの回の用語を参照する側

## 確認パート
- 通常クイズ2〜3問
- 出しどころ: 事例文から4分類のどれかを判別（保険加入＝共有（移転）が定番）／リスク保有が「正しい判断」になる条件
