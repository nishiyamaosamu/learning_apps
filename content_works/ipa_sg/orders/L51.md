# SG-L51 刑法とサイバー犯罪

- **一言で**: 「作る・だます・壊す・偽る」— サイバー行為を罰する刑法の5つの罪
- **シラバス**: 法務#2「刑法」全部
- **主担当**: なし
- **依存**: L48 の後が望ましい（「侵入までは不正アクセス禁止法、その先の行為が刑法」という分担で始めるため）

## 扱う

| 用語・論点 | 何を語るか |
|---|---|
| 不正指令電磁的記録に関する罪（ウイルス作成罪） | マルウェアを作る・提供する・保管するだけで罪。実行前でも成立する |
| 電子計算機使用詐欺罪 | コンピュータに虚偽のデータを入れて財産上の利益を得る。他人のネットバンキングで送金する例で |
| 電子計算機損壊等業務妨害罪 | システムを壊す・データを消すなどで業務を妨害する（R8問7の題材）。DoS攻撃（L12）がここに当たる |
| 電磁的記録不正作出及び供用罪 | 権限なく電子データを作り変える・偽データを使う。紙の文書偽造のデジタル版という整理 |
| 支払用カード電磁的記録不正作出等罪 | カードの磁気・IC情報の偽造。スキミングで読んだ情報の複製カードなど |

## 扱わない
- 不正アクセス行為そのもの → L48（説明済み。「入る行為」と「入った先の行為」の分担を冒頭で一言）
- DoS攻撃・マルウェアの手口 → L5・L12（完成済み、参照のみ）
- 電子署名法・特定電子メール法 → L52
- 民事上の損害賠償の話 → 深入りしない（刑事罰の回と割り切る）

## 確認パート
- 通常クイズ2〜3問
- 出しどころ: 事例と罪名の対応（R8問7の型。データ消去で業務妨害＝電子計算機損壊等業務妨害罪）／ウイルス作成罪は「作っただけ」で成立
