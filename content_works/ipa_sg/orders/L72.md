# SG-L72 システム戦略と業務改善

- **一言で**: 業務のやり方そのものを見直す道具箱 — 作り直す・回し続ける・機械に任せる
- **シラバス**: 中分類9「情報システム戦略」「業務プロセス」「システム活用促進・評価（活用の促進・利用実態の評価）」
- **主担当**: なし
- **依存**: なし

## 扱う

| 用語・論点 | 何を語るか |
|---|---|
| BPRとBPM | 業務プロセスを抜本的に作り直す（BPR）と、継続的に改善し続ける（BPM、R5問11の題材）。一発の手術と日々の健康管理の対比で |
| ワークフローシステム | 申請・承認の流れを電子化する。承認の記録が残る＝内部統制（L71）にも効く、と接続 |
| RPA | 人がやっていた定型のPC操作をソフトウェアのロボットに任せる（R6問11の題材）。RPAのIDと権限の管理を忘れると新しい穴になる、まで |
| BYODとチャットボット | 私物端末の業務利用（便利さとシャドーIT（L2）の危うさ）と、問合せの自動応答。活用促進の代表2つ |
| デジタルリテラシーと普及啓発 | 使う側の力を底上げしないとシステムは活きない。教育（L34）の業務版 |
| 投資対効果と利用実態の評価 | 入れて終わりでなく、効果が出ているか・使われているかを測って見直す。情報システム戦略の組織体制はここで一言（詳細は暗記カード） |

## 扱わない
- 情報システム戦略委員会・組織体制の詳細 → 暗記カード
- システムライフサイクル・廃棄 → L73（調達から廃棄までの流れ側で扱う）
- クラウドサービスの種類（SaaS等）→ L55（説明済み、参照のみ）
- AI・ビッグデータの利活用の流れ → L76

## 確認パート
- 通常クイズ2〜3問
- 出しどころ: BPRとBPMの判別（R5問11の型）／RPAに向く業務の判別（R6問11の型）／BYODのリスク
