# SG-L3 人をだます攻撃

- **一言で**: 最も破られやすいのはシステムではなく人 — 技術を使わない攻撃と、内側から漏れる事故
- **シラバス**: 情報セキュリティ#1「脅威」のうち人為的脅威（ソーシャルエンジニアリング・BEC・SNSの悪用・迷惑メール・内部不正・誤操作・紛失ほか）
- **主担当**: なし（BECの呼称「ビジネスメール詐欺」はこの回が正＝L14が参照済み。作り直しでも呼称を維持する）
- **依存**: L2 の後（脅威の地図の「人為」の枝を深掘る回。呼称は narration/ipa_sg/sg-L2-asset-threat-vuln.md の表に揃える）

## 扱う

| 用語・論点 | 何を語るか |
|---|---|
| ソーシャルエンジニアリング | 技術でなく人の心理・習慣を突く攻撃の総称。肩越しの盗み見（ショルダーハック）・ごみ箱あさり・なりすまし電話を代表例に |
| なりすまし電話の手口 | 「情報システム部ですがパスワードを」——緊急を装い・権威を装い・確認の隙を与えない、という共通の型を見せる |
| ビジネスメール詐欺（BEC） | 取引先や経営者になりすまして送金させる。振込先変更メールの実例型で。呼称は「ビジネスメール詐欺」で読み上げ、画面のみBEC |
| SNSの悪用 | 公開プロフィールから攻撃の材料（在籍・役職・交友）が集まる。攻撃の下調べに使われる、まで |
| 迷惑メール（スパム） | 無差別ばらまきの入口。開かせてからの本番（マルウェア・偽サイト）への導線という位置づけ |
| 人的脅威の地図：内部不正・誤操作・紛失 | 悪意（内部不正）と過失（誤操作・紛失・誤謬）を分けて並べる。事故の多くは悪意なし、が対策（第4章）への伏線 |

## 扱わない
- フィッシング・スミッシング（偽サイトへの誘導）→ L10
- 不正のトライアングル・内部犯の動機 → L6
- 標的型攻撃メール（組織を狙い撃つ型）→ L12
- 標的型メール訓練・教育などの対策 → L34
- 人的脆弱性・シャドーIT → L2（説明済み、参照のみ）

## 確認パート
- 通常クイズ2〜3問
- 出しどころ: ソーシャルエンジニアリングに当たる行為の判別／BECの典型パターン（振込先変更）の見抜きどころ
