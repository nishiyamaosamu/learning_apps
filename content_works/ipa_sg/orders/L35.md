# SG-L35 マルウェア・ランサムウェア対策

- **一言で**: 見つけ方は1つではない — 既知は照合で、未知はふるまいで捕まえ、ランサムには控えで備える
- **シラバス**: 情報セキュリティ#4「技術的セキュリティ対策」のうちマルウェア・不正プログラム対策／マルウェア検出手法／ランサムウェア対策
- **主担当**: なし（攻撃側の正は L4・L5＝完成済み。呼称はその2本に揃える。バックアップ方式の正は L59）
- **依存**: L4・L5 の後（完成済み）。攻撃の再説明はせず対策側に徹する

## 扱う

| 用語・論点 | 何を語るか |
|---|---|
| マルウェア対策ソフトと定義ファイルの運用 | 入れて終わりではなく定義ファイルの更新が命。更新が止まった対策ソフトは古い指名手配書 |
| パターンマッチング法 | 既知のマルウェアの特徴と照合する基本手法。既知にしか効かない、が次の項目への振り |
| ビヘイビア法・ヒューリスティック法 | 未知のマルウェアを「ふるまい」や「怪しい特徴」で見つける。ファイルレス（L5）にはこちら、と接続 |
| コンペア法・チェックサム法 | 正常な状態と比べて改変を見つける。「変わったこと」自体を検知する系統として |
| ランサムウェア対策：バックアップと3-2-1ルール | 暗号化されても戻せる控えを、3部・2種類の媒体・1つは別の場所に。二重脅迫（L5）には万能でない、も正直に言う |
| WORM | 一度書いたら書き換えられない保存。バックアップ自体を暗号化・削除から守る最後の砦 |

## 扱わない
- マルウェアの種類・感染のしかた → L4、ランサムウェア・ボットネットの手口 → L5（完成済み、参照のみ）
- バックアップ方式（フル/差分/増分・世代管理）→ L59。この回では「控えを取る」以上に踏み込まない
- EDR・SIEMなどの製品分類 → L39
- 偽警告（サポート詐欺）への対応 → L93（科目B）
- 検疫ネットワーク → L36
