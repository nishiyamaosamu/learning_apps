# SG-L23 情報資産の分類とリスクの種類

- **一言で**: 守るものに値札を付ける — 何がどれだけ大事かを決めないと、リスクは測れない
- **シラバス**: 情報セキュリティ#2「リスク分析と評価（情報資産の調査・分類）」全部＋「（リスクの種類）」【地図＋代表】
- **主担当**: なし（情報資産・脅威・脆弱性の呼称は L2 が正＝完成済み。narration/ipa_sg/sg-L2-asset-threat-vuln.md の「用語の呼称」表に揃える）
- **依存**: L22 の後（管理の四つの柱のうち「リスクマネジメント」の柱をここから3本で深掘る、と位置づけて始める）

## 扱う

| 用語・論点 | 何を語るか |
|---|---|
| 情報資産の調査 | まず「うちに何があるか」を洗い出す。把握していない資産は守れない（L2のシャドーITを回収） |
| 重要性による分類と管理 | 機密性・完全性・可用性の観点で重要度を格付けする。全部を最高レベルで守るのはコストで破綻する、が動機 |
| 情報資産台帳 | 洗い出した資産と重要度を一覧にした台帳。何を載せるか（資産名・管理者・保管場所・重要度）。L79（科目B）の下敷きになる |
| リスクの種類の地図 | 財産損失・責任損失・純収益の喪失・人的損失の4分類を代表として。「事故で失うものは物だけではない」 |
| サプライチェーンリスク・地政学的リスク | 自社の外からくるリスクの代表2つ。取引先経由・国際情勢という「自社では制御しきれない」性質 |
| 年間予想損失額・得点法 | リスクの大きさを金額や点数で見積もる入口。次回（L24）の定量的・定性的分析への橋渡し |

## 扱わない
- オペレーショナルリスク・外部サービス利用のリスク・SNSによる情報発信のリスク・モラルハザード・コスト要因 → 暗記カード（地図の「他にもある」で一言触れるのみ）
- リスクアセスメントのプロセス（特定→分析→評価）・リスク値の計算 → L24
- リスク対応の4分類 → L25
- 台帳づくりのケース演習 → L79（科目B）

- 出しどころ: 重要度を決める3つの観点（CIA）／台帳に載せる目的／「責任損失」にあたる例の判別
