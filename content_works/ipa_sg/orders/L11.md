# SG-L11 通信を狙う攻撃②：盗聴と改ざん

- **一言で**: 正しい相手と話しているつもりで、あいだに他人が座っている — 通信路への割り込み
- **シラバス**: 情報セキュリティ#1「サイバー攻撃手法」（MITM・DNS・リプレイ系）
- **主担当**: なし。DNS の仕組みの正は L61、TLS による対策の正は L42
- **依存**: L10 の後（誘導 → 割り込み の順）

## 扱う

| 用語・論点 | 何を語るか |
|---|---|
| 【前提】DNS の名前解決 | 名前をIPアドレスに引き直してから通信が始まる、という1枚だけ。**最大2シーン**。詳しくは L61 |
| 中間者（MITM）攻撃 | 双方の間に入り、素通しに見せながら盗聴・改ざんする。**この回の主役**として図を丁寧に |
| MITB攻撃 | 割り込む場所が利用者の**ブラウザの中**。通信を暗号化しても防げない、が要点 |
| DNSキャッシュポイズニング | 名前解決の答えを偽装し、正しいURLのまま偽サーバへ導く |
| リプレイ攻撃 | 盗んだ通信をそのまま再送する。中身が読めなくても成立する |
| 公衆Wi-Fiの危うさ | 身近な例として1シーン。暗号化されていない通信は覗ける |

## 扱わない
- フィッシング・SEOポイズニング・IPスプーフィング → L10
- TLS／HTTPS・IPsec・VPN による対策 → L42・L45
- DNS・DHCP・ルーティングの詳しい仕組み → L61
- 無線LANのセキュリティ設定 → L65

## 確認パート
- 通常クイズ2〜3問
- 出しどころ: MITB が「HTTPSでも防げない」理由／DNSを汚されるとURLが正しくても被害に遭うこと
