# SG-L32 基準・ガイドラインの地図

- **一言で**: 「誰向けのお手本か」で覚える — 経営者・中小企業・IoT・カード業界・共通枠組み
- **シラバス**: 情報セキュリティ#2「情報セキュリティに関する基準」【地図＋代表】＋技術的セキュリティ対策のうち「IoTのセキュリティ」
- **主担当**: なし
- **依存**: なし（L28・L29のISMSの後だと「規格とガイドラインの違い」が言いやすい程度。強い依存はない）

## 扱う

| 用語・論点 | 何を語るか |
|---|---|
| 「誰向けか」の地図 | 基準・ガイドラインは名前でなく対象読者で覚える、が回の背骨。経営者向け／中小向け／モノ向け／業界向け／共通枠組みの5マス |
| サイバーセキュリティ経営ガイドライン | 経営者向け。経営者が認識すべき3原則と、CISOに指示すべき重要10項目、という構造だけ |
| 中小企業の情報セキュリティ対策ガイドライン | 中小企業向け。SECURITY ACTION（L31）とセットで語る |
| IoTセキュリティガイドラインとIoTのセキュリティ | モノ向け。出荷後に放置されがち・パッチが当てにくいというIoT特有の弱点とセットで |
| PCI DSS | カード業界の基準。カード情報を扱うなら準拠が求められる、業界基準の代表として |
| サイバーセキュリティフレームワーク（CSF） | 共通枠組み。識別・防御・検知・対応・復旧（＋統治）の機能で対策を整理する考え方 |

## 扱わない
- コンピュータウイルス対策基準・コンピュータ不正アクセス対策基準・ソフトウエア製品等の脆弱性関連情報に関する取扱規程・政府機関等の統一基準群・サイバー・フィジカル・セキュリティ対策フレームワーク・金融機関等安全対策基準 → 暗記カードへ委譲（**これは範囲切り分けの内部記録**。地図の中で名前だけ見せ、暗記カードなど他機能への誘導はナレーション・画面に書かない）
- JIS Q 27001/27002（規格）→ L28・L29（参照のみ。「認証を受ける規格」と「従うと良いお手本」の違いに一言触れる）
- 個人情報保護法関連の制度（プライバシーマークなど）→ L50

## 確認パート
- 通常クイズ2〜3問
- 出しどころ: 事例（経営者が読むべきものは？カード情報を扱う会社は？）から該当ガイドラインを選ぶ
