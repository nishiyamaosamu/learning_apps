# SG-L17 デジタル署名とメッセージ認証

- **一言で**: 「本人が作り、改ざんされていない」を技術で証明する
- **シラバス**: 情報セキュリティ#1「情報セキュリティ技術（認証技術）」のうち デジタル署名・タイムスタンプ・メッセージ認証（チャレンジレスポンス認証はL18、リスクベース認証はL19へ）
- **主担当**: なし（メッセージダイジェストの定義は L16 が正・公開鍵ペアの仕組みは L15 が正。この回の署名の説明を L21・L52 が前提にする）
- **依存**: L15・L16 の後（公開鍵ペアとメッセージダイジェストを説明済みとして使う）

## 扱う

| 用語・論点 | 何を語るか |
|---|---|
| デジタル署名で証明できること | 「本人が作成した」（真正性・否認防止）と「改ざんされていない」（完全性）の2つ。L1のCIA+αを回収する |
| 署名鍵・検証鍵 | 公開鍵ペアの応用。暗号化とは鍵の使う向きが逆 — **秘密の鍵で署名し、公開された鍵で誰でも検証できる** |
| ダイジェストに署名する流れ | 文書全体でなくL16のメッセージダイジェストに署名する。受信側は再計算して照合、という一連の流れを図で |
| タイムスタンプ（時刻認証） | 「その時刻にその文書が存在し、以後変わっていない」を第三者が証明する。署名が「誰が」なら、こちらは「いつ」 |
| メッセージ認証符号（MAC） | 共通鍵で作る改ざん検知の符号。署名との違いは「共通鍵を知る二者間でしか使えず、第三者への証明・否認防止ができない」の一言 |

## 扱わない
- 署名した公開鍵が本物かの保証（デジタル証明書・認証局） → L21
- 電子署名法・認定認証事業者・電子証明書 → L52
- チャレンジレスポンス認証 → L18、リスクベース認証 → L19
- S/MIME・PGP（メールでの利用） → L44

## 確認パート
- 通常クイズ2〜3問
- 出しどころ: 署名に使う鍵はどちらか（署名鍵＝秘密）／デジタル署名で確認できること2つ／タイムスタンプが証明すること
